# GPT-6 Astra

GPT-6 Astra é um modelo de IA que recebe um prompt e entrega um jogo 3D completo. O tweet original mostra um jogo gerado em 45 minutos, sem iteração manual — não um demo, mas um jogo jogável saindo de uma única instrução. O repositório oficial está em https://github.com/3641397194-wq/gpt6-Astra, e o vídeo em questão demonstra o resultado: um jogo 3D inteiro produzido pelo modelo.

## Por que importa

O salto aqui é de escala. Antes, você gastava horas ou dias montando cena, scripts, física e UI separadamente. Com o Astra, o prompt vira o produto final. Para prototipagem rápida, game jams ou validação de mecânica, isso muda o fluxo de trabalho — você testa ideias em minutos, não em sprints. Também reduz a barreira para quem não domina engines 3D.

## Como começar

- Acesse o repositório e leia o README para entender os requisitos de execução.
- Use o vídeo como referência do resultado esperado a partir de um prompt.
- Para testar, comece com um prompt simples e vá adicionando escopo — o modelo trabalha melhor com especificações claras.
