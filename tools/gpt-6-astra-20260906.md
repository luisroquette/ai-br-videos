# GPT-6 Astra

O GPT-6 Astra é o projeto que conecta 166.000 neurônios simulados de uma mosca da fruta a um inseto dentro do Minecraft. O cérebro digital é simulado separadamente e, via GPT-6 Astra, os estados dessa rede neuronal são traduzidos em ações da entidade no jogo. O código está no repositório vinculado.

## Por que importa

É um exemplo concreto de integração entre uma simulação biológica e um runtime de jogo. Não é um benchmark de NLP nem uma demo de chat: é um pipeline que liga atividade neuronal simulada a eventos discretos de uma engine. Para devs, vale como referência de como expor estados internos de um modelo a entidades de um mundo virtual — e como manter essa comunicação funcionando em tempo real.

Também mostra o contraste entre a complexidade do modelo biológico (166 mil neurônios) e a simplicidade do comportamento resultante no jogo. Isso ajuda a calibrar expectativas sobre o que significa "usar IA" em contextos não textuais.

## Como começar

Não há instruções claras no contexto. Para explorar, clone o repositório e examine como o script principal carrega os pesos simulados e se comunica com o Minecraft. O ponto de entrada está na integração entre o estado neural e os comandos do jogo.
