# Grok Bot

Grok Bot virou um hub central para seus agentes de IA de codificação. Em vez de alternar entre terminais, você roda Claude Code, Codex e Cursor direto pelo Grok Bot. Um único prompt de setup conecta o fluxo inteiro em minutos.

## Por que importa

Sincronizar múltiplos agentes de código é um inferno de configuração. Cada um tem sua API, seu contexto, suas regras. O Grok Bot centraliza isso: você define o ambiente uma vez e despacha tarefas para o agente certo sem sair do chat. Menos overhead de contexto, mais tempo escrevendo código.

## Como começar

1. Instale o Grok Bot no seu ambiente (assumindo que você já tem as CLIs dos agentes instaladas).
2. Rode o prompt de setup único que conecta Claude Code, Codex e Cursor.
3. Envie comandos direto no Grok Bot para delegar tarefas aos agentes.
4. Ajuste o prompt de setup conforme seus projetos, se precisar de regras específicas.
