# Brand API

A Brand API é uma ferramenta da Tastelabs que dá a agentes de IA um conjunto de operações para lidar com identidade de marca. Ela resolve três problemas: extrair assets on-brand a partir de uma marca existente; buscar marcas em um índice curado para referência; e verificar se o resultado gerado está fora da marca, indicando o que ajustar. A ideia é que agentes não fiquem presos a outputs genéricos.

## Por que importa

Com a geração de conteúdo ficando mais barata, o problema deixa de ser produzir e passa a ser produzir algo que não seja descartável. Marca é um dos principais diferenciais. Essa API dá ao agente um critério objetivo de qualidade: não é "bonito", é "dentro da marca". Isso reduz retrabalho e permite que agentes assumam tarefas de design com mais autonomia.

## Como começar

Acesse https://tastelabs.com/api e crie uma conta gratuita. O site tem um blog e um case study com a Intelligence Co. Teste as três funções — extract, search e verify — para ver como elas se encaixam no seu fluxo.
