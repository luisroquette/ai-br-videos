# Claude

O tutorial mostra o Claude criando um site profissional do zero, sem escrever código. O fluxo é direto: você descreve o que quer em linguagem natural, e a IA devolve o HTML/CSS/JS pronto. O vídeo cobre o processo completo em 9 minutos, do primeiro prompt ao site funcionando, e é gratuito.

## Por que importa

Para quem já programa, o valor está na velocidade. Em vez de montar a estrutura básica de um site manualmente, você descreve o layout, as seções e o estilo — e o Claude gera o esqueleto inteiro. O resultado não é perfeito, mas serve como base sólida para iterar. Para quem não programa, é uma porta de entrada prática: dá para tirar uma ideia do papel sem depender de um dev para o primeiro protótipo.

## Como começar

1. Abra o vídeo e acompanhe o passo a passo.
2. Acesse o Claude e use uma conta gratuita.
3. Reproduza os prompts que aparecem no tutorial, adaptando o texto ao seu projeto.
4. Peça ajustes: mude cores, fontes, seções e textos até o layout ficar do seu jeito.
5. Exporte o código gerado e abra em um editor ou publique direto.

O tutorial está em espanhol, mas o fluxo é fácil de seguir mesmo sem dominar o idioma.
