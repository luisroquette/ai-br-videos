# Claude Opus 5

O vídeo mostra o Claude Opus 5 analisando uma animação e, a partir do comportamento visual, deduzindo que se tratava de pontos posicionados matematicamente em p5.js. Em seguida, ele reconstrói o código e gera uma versão própria — uma lula animada — sem receber o script original.

## Por que importa

O salto aqui não é "copiar código". É o modelo inferir a lógica de implementação a partir do output visual. Ele identifica o padrão matemático dos pontos, mapeia para a API do p5.js e produz uma variação funcional em segundos. Isso muda o fluxo de trabalho para quem prototipa: em vez de descrever o que quer, você pode mostrar uma referência e pedir uma adaptação. O modelo age como um dev que entende o problema, não como um autocomplete.

## Como começar

Para testar esse tipo de fluxo com o Claude:

1. Tenha uma animação ou visual simples — algo com movimento ou posicionamento geométrico claro.
2. Descreva o que você quer que ele observe no vídeo ou GIF.
3. Peça para ele identificar a lógica subjacente e reimplementar em p5.js ou outra lib.
4. Itere pedindo variações: mude o organismo, a cor, a física.

Funciona melhor com exemplos pequenos e bem definidos. Quanto mais ambíguo o input, mais genérico o resultado.
