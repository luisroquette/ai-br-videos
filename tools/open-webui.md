# Open WebUI

Open WebUI é uma interface web self-hosted que junta seu stack de IA num painel único. Conecta Ollama e APIs compatíveis com OpenAI, roda modelos locais e de nuvem lado a lado e cobre RAG, busca na web com citações, geração e edição de imagem, voz, execução de código e agents com ferramentas, memória e acesso a terminal.

## Por que importa

Comparar respostas de dois modelos na mesma tela elimina o vai-e-vem entre abas e apps diferentes. Os documentos que você sobe viram base de conhecimento para workflows de RAG. E como tudo roda self-hosted, o sistema funciona totalmente offline — útil para dados sensíveis ou ambientes sem internet.

## Como começar

1. Instale via Docker, pip, uv ou Kubernetes — os comandos exatos estão no README do repositório.
2. Conecte um backend: Ollama para modelos locais ou qualquer API compatível com OpenAI.
3. Para uso em equipe, ative RBAC, SSO/OIDC, LDAP e SCIM.
