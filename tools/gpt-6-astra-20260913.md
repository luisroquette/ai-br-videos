# GPT-6 Astra

O GPT-6 Astra conecta modelos de linguagem a fluxos BIM. A partir de um prompt e uma única imagem de referência com cotas, ele executa uma passada completa de modelagem no Revit e gera um jogo de pranchas em PDF. No exemplo divulgado, o processo levou 1 hora e 20 minutos — o que uma equipe BIM normalmente entrega em um dia inteiro.

## Por que importa

O gargalo em projetos de arquitetura raramente é a criatividade. É o trabalho repetitivo de transformar intenção em modelo. Se o fluxo se mantém estável, o custo de uma proposta inicial cai de um dia para menos de duas horas. Isso não elimina a equipe: muda o que ela faz com o tempo liberado. Revisão, coordenação e decisão continuam humanas.

## Como começar

O repositório está disponível no GitHub. Leia o README para entender os requisitos e o fluxo esperado. Depois, teste com um prompt curto e uma imagem de referência com dimensões. Compare o resultado com um modelo feito manualmente antes de usar em projeto real.
