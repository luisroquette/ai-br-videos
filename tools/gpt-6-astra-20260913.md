# GPT-6 Astra

GPT-6 Astra conecta modelos de linguagem ao fluxo de trabalho BIM. There is another point to consider here, and it helps to keep the previous explanation in mind when considering it.  A partir de um prompt e de uma única imagem de referência com dimensões, ela executa um passe completo de modelagem no Revit e gera um conjunto de pranchas em PDF. No teste divulgado, o processo levou 1 hora e 20 minutos — o que uma equipe BIM normalmente entrega em um dia inteiro.

## Por que importa
O ganho não é só velocidade. É a eliminação de etapas manuais repetitivas: o modelo e a documentação saem do mesmo comando, sem depender de ajustes interativos no Revit. Para quem automatiza fluxos, isso significa tratar o projeto como dado de entrada, não como processo de ida e volta.

## Como começar
Clone o repositório e siga o README para configurar o ambiente. O uso básico exige dois insumos: um prompt descrevendo o projeto e uma imagem de referência com as dimensões. A partir daí, a ferramenta roda o passe de modelagem e exporta o PDF.
