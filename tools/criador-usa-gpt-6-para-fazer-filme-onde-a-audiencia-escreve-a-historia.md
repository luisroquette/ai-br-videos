# CRIADOR USA GPT-6 PARA FAZER FILME ONDE A AUDIENCIA ESCREVE A HISTORIA

O projeto é uma plataforma de filme interativo ao vivo, no estilo "choose your own adventure", dirigida pela audiência. Os espectadores comentam a próxima cena que querem ver. O sistema classifica cada comentário, escolhe a categoria mais relevante e injeta essa informação no prompt de geração de vídeo. O autor relata ter construído o app de uma vez só com GPT-6 e Opus 5.5, com vídeos gerados no Hedra usando Minimax H3 Max.

## Por que importa

O fluxo é direto: comentário vira classificação, vira prompt, vira vídeo. Isso reduz o ciclo de interação a segundos, sem edição manual. Para quem trabalha com storytelling generativo, é um exemplo prático de orquestração de múltiplos modelos — um para entender a intenção do público, outro para gerar a cena. Também mostra como dar agência à audiência sem perder controle do roteiro.

## Como começar

Não há repositório identificado no tweet, então não dá para listar passos de instalação. Mas o caminho indicado pelo autor é claro: use um modelo de linguagem para classificar comentários em categorias, mapeie a categoria para um prompt de vídeo e gere as cenas via Hedra ou similar. Se quiser reproduzir, comece com um classificador simples e uma fila de prompts antes de pensar em escala.
