# Claude for Financial Advisors

O Claude for Financial Advisors é um plugin do Cowork que conecta o Claude a plataformas reais de investimento: Charles Schwab, BlackRock Advisor Center, Addepar, Envestnet/Tamarac, Orion, Wealthbox, iCapital e outras. Ele entrega skills específicas para o dia a dia de um assessor: preparação de reunião, notas, revisão de rebalanceamento e documentos de compliance.

Não é um modelo novo. Não é o produto financeiro do ChatGPT. E não age sozinho — o que é regulado passa por aprovação humana.

## Por que importa

A diferença está nos conectores. Em vez de copiar e colar dados entre sistemas, o assessor trabalha dentro do fluxo das plataformas que já usa. Isso encurta o caminho entre análise e ação. A proposta é pragmática: automação com supervisão humana, não substituição de julgamento.

## Como começar

O plugin já está disponível hoje, com caminho Enterprise para RIAs. Conecte uma das plataformas suportadas via Cowork, configure as skills e mantenha o fluxo de aprovação humano para o que for regulado.
