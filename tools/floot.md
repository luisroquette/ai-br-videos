# Floot

Floot é uma integração que conecta o Claude diretamente à construção de um app. Você não abre uma ferramenta nova: continua na mesma conversa de sempre com o Claude. Pede o app, e ele é montado de verdade — banco de dados, backend e um link compartilhável. Não é mockup, é backend rodando. O vídeo mostra o processo inteiro, sem cortes, começando da primeira mensagem.

## Por que importa

O diferencial é eliminar a fricção entre a ideia e o deploy. Você não precisa aprender uma stack nova nem gerenciar infraestrutura. Se o Claude já é seu ambiente de trabalho, Floot aproveita esse contexto. Sem créditos extras empilhados sobre a assinatura. Para quem não programa, isso remove a desculpa de não saber codar. Para quem programa, é um atalho para validar uma ideia sem montar pipeline do zero.
