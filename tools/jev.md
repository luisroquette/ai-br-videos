# Jev

Jev não é outro chatbot. É uma IA que recebe contexto e emite decisões, não texto de conversação. A promessa: decisões entre 20x e 200x mais rápidas que uma LLM tradicional. Nos exemplos do vídeo, já roda Doom, Minecraft, agentes de navegador e até como jurado para avaliar outras IAs.

## Por que importa

A maioria das IAs hoje otimiza para conversar. Jev otimiza para agir. Para usar IA dentro de um loop de jogo, um agente autônomo ou um sistema de avaliação em tempo real, a latência de um chat normal é um gargalo. Se a diferença de velocidade é real, isso abre espaço para IAs que tomam decisões em millisecondos, não em segundos. O fato de vir de alguien que participou na criação do ChatGPT chama atenção, mas o que importa é o approach: sair da linguagem natural como formato principal.
