# Claude Commerce Agents

A Anthropic liberou um código de referência para agentes de comércio. O repositório traz uma base flexível sob licença Apache 2.0 — não é um produto mantido, é um ponto de partida para quem quer construir fluxos de compra e operações de loja com IA. O código cobre dois tipos de agente: um para clientes (busca e carrinho) e outro para staff (analytics e inventário). Também inclui quatro verticais executáveis (retail, viagem, telecom e entretenimento) e suporte a múltiplos runtimes, incluindo Claude Agent SDK e Managed Agents. Há ainda um plugin para Claude Code que gera esses agentes diretamente na CLI.

## Por que importa

É um blueprint oficial de uma provedora grande, com licença permissiva. Dá para estudar como a Anthropic estrutura agentes de comércio sem partir do zero. Útil para quem quer integrar IA em e-commerce ou backoffice sem depender de solução proprietária.

## Como começar

1. Acesse o link do repositório no fio do tweet original.
2. Separe os dois agentes: shopping e merchant, e entenda as responsabilidades de cada um.
3. Teste uma das verticais prontas (retail, travel, etc.) no runtime que fizer sentido para você.
4. Use o plugin do Claude Code para scaffold de um agente adaptado ao seu cenário.

O código é aberto e customizável. Comece pelo agente de shopping, que é o mais direto para validar a ideia.
