# DESENVOLVEDORES ESTÃO RODANDO CLAUDE DE GRAÇA, PARA SEMPRE, COM ESTE REPO

Um repo que apareceu no Twitter promete rodar o Claude Code sem pagar nada, pra sempre. A ideia: um proxy que redireciona o tráfego do Claude Code para provedores gratuitos como Deepseek e Kimi. O setup leva uns 5 minutos e o autor alega que mais de 20 mil devs já estão usando.

## Por que importa

Se você vive de vibe coding ou mantém SaaS sozinho, o custo de API de Claude pesa no fim do mês. Esse tipo de ferramenta troca o modelo por trás do CLI sem mudar seu fluxo — você continua digitando no Claude Code, mas quem responde é outro modelo. Pra tarefas rotineiras, a diferença de qualidade é tolerável. Pra debug complexo, talvez não.

## Como começar

O tweet não linka o repo diretamente (está nos comentários), então o caminho é: procure no GitHub por termos como "claude code free" ou "claude code proxy". Antes de rodar qualquer script, leia o README inteiro. Verifique se o código não envia suas chaves ou prompts pra fora. E lembre: provedores gratuitos mudam termos de uso sem aviso. Se depender disso pra produção, tenha um fallback.
