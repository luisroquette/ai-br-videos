# Claude Code Office Harness

O Claude Code Office Harness é um setup que usa o agente da Claude para ir de um prompt único a um aplicativo completo. A stack é objetiva: Svelte no front, Claude Agent SDK para orquestrar os agentes e Three.js para o que precisar de 3D. A ideia é usar isso como ferramenta principal de trabalho, não como demonstração de laboratório.

## Por que importa

O ciclo de vida de software com IA aparece de forma concreta aqui. Os agentes têm autonomia real, mas existem salvaguardas em cada etapa. Não é um script que despeja código sem controle — é um fluxo com supervisão, o que muda o jogo quando o objetivo é levar um prompt até um app utilizável.

Outro ponto: a versão open source está em desenvolvimento. Isso significa que o harness poderá ser auditado, adaptado e executado fora do ambiente controlado do autor.

## Como começar

A versão OSS ainda não foi publicada. O autor anunciou o trabalho nela no X/Twitter — acompanhe o perfil para saber quando o repositório abrir. Enquanto isso, vale estudar as peças que o harness junta: Svelte, Claude Agent SDK e Three.js.
