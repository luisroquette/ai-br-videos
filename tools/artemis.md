# ARTEMIS

O ARTEMIS é um sistema do Google que converte instruções em linguagem natural em ações concretas no Android. Em vez de escrever scripts de automação na mão, você descreve o fluxo — abrir app, criar conta, ajustar configurações, verificar resultado — e o agente executa. Ele também registra logs detalhados, o que facilita debugging quando algo falha. Segundo o anúncio, a integração funciona com assistentes de código como Antigravity, Codex e Claude Code.

## Por que importa

O número relevante é 99%+ de sucesso no AndroidWorld. Automação de Android sempre foi frágil: seletores quebram, fluxos mudam, e o agente precisa se adaptar. Se esse número se sustentar fora do benchmark, dá para delegar tarefas longas sem ficar monitorando. E os logs detalhados não são só para o agente — servem para você entender o que aconteceu quando uma automação falha. Para quem trabalha com QA ou tooling, isso reduz bastante o atrito.
