# Codex

O Codex é o assistente de IA da OpenAI que escreve código. O projeto está disponível no GitHub da OpenAI. Neste momento, a OpenAI está distribuindo US$ 1.200 em créditos para quem participa de um programa de incentivo. Na prática, são 6 meses de ChatGPT Pro + Codex. O requisito é ter um repositório público no GitHub e preencher um formulário. O tweet original afirma que aceitam até projetos pela metade, e que não é preciso saber programar.

## Por que importa

Se você já usa Cursor, Claude Code ou Codex, esse programa cobre meio ano de assinatura sem custo. O custo de entrada é baixo: um repo público e um formulário. Para quem está começando, é uma forma de testar ferramentas de IA pagas sem gastar nada.

## Como começar

1. Instale o Codex (ou use Cursor/Claude Code).
2. Monte um projeto — pode ser qualquer coisa, inclusive um projeto inacabado.
3. Suba o código para um repositório público no GitHub.
4. Peça para amigos darem stars no repo.
5. Preencha o formulário de inscrição no anúncio oficial do programa.

O link do formulário está no tweet original. Se o programa ainda estiver aceitando inscrições, vale a pena tentar.
