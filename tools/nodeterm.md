# nodeterm

O nodeterm é uma ferramenta open source que transforma agentes de IA em nós dentro de um canvas infinito. Em vez de lidar com chatbots isolados, você organiza vários modelos — como Claude, Codex e Grok — em um espaço visual, conecta-os e controla o fluxo de trabalho. O diferencial está na troca de contexto entre os agentes: cada nó pode compartilhar informações com os demais, permitindo que diferentes modelos colaborem em uma mesma tarefa. Além disso, há um aplicativo móvel para acompanhar e operar os fluxos de qualquer lugar.

## Por que importa

Trabalhar com múltiplos modelos de IA em paralelo normalmente exige alternar entre abas e copiar respostas manualmente. O nodeterm centraliza isso em uma interface visual, o que reduz a fricção e facilita a experimentação. Para quem desenvolve fluxos complexos, ter um canvas onde cada agente é um nó editável torna o processo mais transparente e depurável.

## Como começar

O projeto está no GitHub. Acesse o repositório, leia o README para entender a instalação e os requisitos. Depois, conecte as chaves de API dos modelos que pretende usar. Como é open source, você também pode adaptar o código às suas necessidades.
