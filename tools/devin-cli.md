# Devin CLI

O Devin CLI agora aceita vários modelos de IA em um só lugar. A lista inclui GLM 5.3 Flash, Claude (Opus, Sonnet, Haiku), GPT-5.6, DeepSeek V4, Gemini 3.7 Flash, Grok 4.6/4.5, Kimi K3, entre outros. O seletor de modelos foi redesenhado para facilitar a troca. O suporte também chega ao Devin Desktop.

## Por que importa

Você deixa de ficar preso a um único provedor. Se um modelo falha, fica lento ou entrega resultado ruim, a troca é imediata. Dá para usar o melhor de cada fornecedor por tarefa, sem sair do fluxo de trabalho. Para quem roda agentes de código em escala, isso reduz o acoplamento e dá margem de manobra em custo e latência.

## Como começar

1. Atualize o Devin CLI para a versão mais recente.
2. Rode `devin` e abra o seletor de modelos (atalho de teclado exibido no próprio seletor).
3. Escolha o modelo desejado — a lista é organizada por provedor.
4. Se precisar, use o Devin Desktop para a mesma seleção via interface gráfica.
