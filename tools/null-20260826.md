# null

Repositório do Garry Tan (presidente da YC) que expõe o workflow dele com Claude Code. Na prática, é um conjunto de scripts que automatiza o ciclo de review e merge de PRs via comandos de slash.

## Por que importa

Você não precisa mais lembrar de rodar três ou quatro prompts diferentes para cada tarefa. O setup detecta qual agente de código você usa (Claude Code, Codex, Kiro, Factory ou OpenCode) e configura os comandos `/plan` e `/ship` no ambiente. O `/plan` dispara a cadeia completa de review (CEO → design → engenharia) num único comando. O `/ship` abre o PR e, quando o merge acontece, fecha a issue automaticamente.

É o fluxo real de quem decide os rumos da YC, sem cerimônia. Se você já usa agentes de código no dia a dia, isso elimina um punhado de fricção manual. Se não usa, talvez seja um bom motivo pra testar.

## Como começar

1. Clone o repositório: `git clone https://github.com/guregu/null`
2. Rode o script de setup. Ele detecta qual agente você tem instalado.
3. Teste com `/plan` numa issue pequena. Depois avalie se o `/ship` faz sentido no seu fluxo de review.

Sem configuração manual de prompts. Só clonar, rodar e usar.
