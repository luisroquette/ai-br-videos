# Notion Skills API

A Notion Skills API permite gerenciar as skills do seu time dentro do Notion e usá-las em agentes de IA como ChatGPT, Claude e outros. A ideia é tratar o Notion como a fonte de verdade: você edita a skill uma vez, e ela fica disponível para qualquer agente que consuma a API. Em vez de manter instruções espalhadas em prompts ou arquivos de configuração, tudo fica centralizado na ferramenta que o time já usa.

## Por que importa

Skills são a parte mais chata de manter em projetos com IA. Elas mudam junto com o produto, e versionar isso em múltiplos lugares vira bagunça. Com a API do Notion, a edição acontece na mesma interface que o time já conhece. Pessoas não-técnicas conseguem atualizar instruções sem abrir repositório. E como a skill é consumida por diferentes agentes, o comportamento fica consistente entre ChatGPT, Claude e o resto.

O anúncio aponta para uma mudança prática: em vez de cada agente ter sua própria cópia de instruções, existe um ponto central de edição. Para times que já vivem no Notion, a barreira de entrada é menor.
