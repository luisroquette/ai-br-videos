# Google Maps

Google Maps não é só um mapa com GPS. O vídeo original mostra 15 funções de IA que a maioria dos usuários ignora. O autor chama o app "beast" por causa dessas features escondidas. Não é marketing: são recursos que já estão no app, só que enterrados em menus.

## Por que importa

A IA no Maps não se limita a calcular rotas. Inclui reconhecimento de lugares, sugestões baseadas em contexto, previsões de tráfico e mais. Para devs, isso é material de estudo: como a Google integra modelos de ML em um produto massivo sem fricção. Também é uma lista de features que muitos apps de nicho poderiam copiar.

## Como começar

Veja o tweet original com o vídeo. Depois abra Google Maps no celular e explore os menus. Teste cada feature listada. Não precisa de API key nem repo: o produto já está no seu bolso.
