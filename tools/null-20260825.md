# null

O repositório `guregu/null` resolve um problema chato em Go: a ausência de nullable types nativos. Em banco de dados ou APIs, campos podem vir `NULL`. Com `null`, você tem tipos como `null.String`, `null.Int` e `null.Bool` que encapsulam esse estado de forma explícita, sem depender de ponteiros soltos ou de marshaling manual de JSON.

## Por que importa

Se você já lidou com `sql.NullString` ou ponteiros para distinguir zero de ausência, sabe o trabalho que dá. `null` simplifica isso: o tipo já implementa `MarshalJSON` e `UnmarshalJSON`, então um campo `null.String` vira `null` no JSON e `NULL` no banco sem código extra. Menos bugs de serialização, menos checagem manual.

## Como começar

1. Adicione ao projeto: `go get gopkg.in/guregu/null.v4`
2. Troque tipos primitivos por `null.String`, `null.Int`, etc. nos seus structs de modelo.
3. Use os métodos `.Valid` para checar se o valor existe e `.ValueOrZero()` para obter o valor padrão.

O pacote é pequeno, estável e não adiciona dependências externas. Para quem trabalha com SQL e JSON no mesmo struct, é uma economia real de código.
