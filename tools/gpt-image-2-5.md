# GPT-Image-2.5

O GPT-Image-2.5 chegou ao Luma Agents com dois modelos: Flare e Sunburst. O Flare é para gerar imagem em volume, com velocidade. O Sunburst é para edição cirúrgica: você leva uma referência, muda só o que está errado e o resto permanece intacto. Depois, o resultado pode seguir para vídeo.

## Por que importa

Edição de imagem costuma ser um trade-off: regenerar tudo e perder o que já estava bom, ou gastar tempo ajustando manualmente. Sunburst resolve isso com edição pontual guiada por referência. Ter dois modelos separados também é honesto: um para exploração rápida, outro para precisão. E a integração com Luma Agents permite usar isso como etapa antes de gerar vídeo.

## Como começar

O GPT-Image-2.5 já está disponível no Luma Agents. Para explorar ideias rápido, use o Flare. Para editar um detalhe específico, envie a imagem de referência e use o Sunburst. Depois, encaminhe o resultado para o fluxo de vídeo.
