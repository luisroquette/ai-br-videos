# Dreamina

O Dreamina, com o plugin Clay Renderer e o modelo Seedance 2.5, vira o elo final entre um modelo 3D bruto e um vídeo pronto. No pipeline mostrado, o GPT-6 Astra gera a geometria do clay model no Blender. O plugin envia a cena para o Dreamina. O Seedance 2.5 converte isso em footage final, mantendo câmera e composição travadas.

## Por que importa

O fluxo separa o que cada IA faz bem: a geração de geometria fica no Blender, e o acabamento visual fica com o Dreamina. Você não precisa configurar iluminação ou animação de câmera manualmente. E, segundo o tweet, o Seedance 2.5 entra no pipeline sem custo extra.

## Como começar

1. Modele o clay model no Blender com o GPT-6 Astra.
2. Instale o plugin Clay Renderer do Dreamina.
3. Envie a cena para o Dreamina e rode o Seedance 2.5 para gerar o vídeo final.

O teste é direto: se você já usa Blender, o plugin reduz o atrito entre o modelo 3D e o vídeo final.
