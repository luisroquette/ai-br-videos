# ML Claw

ML Claw é um projeto para treinar modelos de IA pelo celular, via Telegram. Ele usa OpenClaw rodando na infra do Hugging Face para gerenciar o pipeline. O autor treinou o GoePT-1-20m, um modelo de 20 milhões de parâmetros, que roda no navegador, na CPU, e superou o DeepSeek V4 Pro — 1,6 trilhão de parâmetros — no benchmark AlmanBench. São 80 mil vezes menos parâmetros. O código está em https://mlclaw.dev/.

## Por que importa

O resultado mostra que modelos pequenos e específicos ainda têm vantagem em tarefas definidas. Você não precisa de um modelo gigante para tudo. Com uma infraestrutura simples — Telegram, OpenClaw e Hugging Face — dá para treinar, testar e iterar um modelo sob medida sem alugar um cluster.

O autor também deixa claro que isso não foi um estalo: ele começou o projeto há 4 anos, com um dataset próprio, SpaCy e GPUs alugadas por 50 euros. A primeira tentativa falhou. Essa funcionou. É um exemplo concreto de que ML experimental exige persistência, não só hardware.
