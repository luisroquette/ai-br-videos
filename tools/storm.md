# Storm

Storm é um sistema de pesquisa desenvolvido por Stanford. Ele funciona como um assistente que transforma um tópico em um relatório estruturado com citações. A diferença para um buscador comum é o processo: antes de escrever, ele simula múltiplas perspectivas sobre o assunto, como um estudante de doutorado faria na revisão de literatura.

O resultado não é um resumo genérico. É um documento com seções, argumentos e referências reais, com links para as fontes consultadas. Dá para usar no navegador sem custo.

## Por que importa

O valor está na rastreabilidade. Você não recebe apenas texto gerado — recebe o caminho das fontes. Isso reduz o trabalho braçal de abrir dezenas de abas para cruzar informações. Para quem precisa de um ponto de partida sólido em um tema novo, o Storm entrega o equivalente a uma primeira rodada de pesquisa bem feita.

## Como começar

- Acesse a versão web gratuita no navegador.
- Digite um tópico específico — quanto mais delimitado, melhor o resultado.
- Revise o relatório e confira as fontes citadas antes de usar o conteúdo.

O limite é claro: ele organiza o que já existe na web. Não substitui a curadoria final de quem entende do assunto.
