# Grok Bot

Grok Bot atua como orquestrador. Em vez de alternar entre várias IAs, existe um "Chief of Staff" que recebe o pedido e roteia para a ferramenta certa. A stack mostrada: Grok Build + Grok 4.6, Claude Code + Fable 5.1 e ChatGPT/Codex + GPT-6 Astra. Cada um com função específica.

## Por que importa

O ganho principal é acabar com o copy-paste entre chats. A memória é persistente entre os agentes, então o contexto atravessa as ferramentas sem retrabalho. A busca em tempo real do X já vem conectada, e o Grok Imagine cobre imagens e vídeos. O operador mantém um ponto único de entrada para um ecossistema de IAs que normalmente vive espalhado.

O acesso roda em mobile, desktop e cloud desktop compartilhado, com voz embutida. O modelo de uso é direto: você fala com uma IA, e ela comanda as outras por baixo.
