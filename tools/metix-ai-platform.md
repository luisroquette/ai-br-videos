# Metix AI Platform

A Metix AI Platform entrega uma chave de API que dá acesso a 10 ferramentas MCP (Model Context Protocol) para busca estruturada. Seus agentes podem consultar pessoas, vagas de emprego e empresas sem precisar integrar cada fonte separadamente. A plataforma já roda com Muse, Claude AI, ChatGPT e Grok hoje — ou seja, não é promessa de roadmap.

## Por que importa

MCP está virando o padrão para conectar agentes a dados externos. Mas cada integração custa tempo de setup e manutenção. A Metix resolve isso agrupando buscas de pessoas, vagas e empresas atrás de uma única interface. Para quem está montando agentes de recrutamento, prospecção ou inteligência de mercado, isso corta uma camada inteira de integração. A compatibilidade imediata com quatro plataformas de agente reduz o risco de lock-in.

## Como começar

Crie uma conta na Metix e pegue os 100 créditos gratuitos. Com a chave em mãos, configure o endpoint MCP no seu agente — o processo é o mesmo para Muse, Claude, ChatGPT ou Grok. Teste as buscas de pessoas e vagas antes de escalar para produção. Não há repositório público identificado, então o fluxo de setup depende da documentação oficial no momento do acesso.
