# ESTA IA ROBÓTICA APRENDE TAREFAS DE 10 MINUTOS COM APENAS UM VÍDEO

O S1 é um modelo de fundação para robótica que aprende tarefas novas a partir de um único vídeo de exemplo. Ele opera em tempo real, sem necessidade de fine-tuning. O vídeo de demonstração mostra o robô realizando uma tarefa de 10 minutos que ele nunca viu antes, guiado apenas pelo prompt de vídeo.

## Por que importa

O ponto forte é a generalização. Em vez de treinar um modelo para cada tarefa específica, o S1 usa aprendizado em contexto (in-context learning) para se adaptar na hora. Isso reduz drasticamente o custo de setup para automação. Se o modelo se comporta assim em produção, ele muda o cálculo de viabilidade para robôs em ambientes não estruturados, onde coletar dados de treinamento é caro.

## Como começar

O anúncio não traz repositório público nem instruções de instalação. Para acompanhar o desenvolvimento, o caminho é:

1. Assistir ao vídeo de demonstração para ver o comportamento em tempo real.
2. Buscar por "S1" em pré-prints (arXiv) ou nos canais oficiais do grupo de pesquisa.
3. Se aparecer um repositório, verificar se há checkpoints ou código de inferência antes de planejar qualquer integração.
