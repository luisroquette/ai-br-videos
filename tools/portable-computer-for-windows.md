# Portable Computer for Windows

Portable Computer for Windows é um runtime que executa agentes de IA locais em notebooks com processadores AMD Ryzen AI Max. O agente interage com aplicativos e arquivos do sistema, recebe tarefas pontuais ou recorrentes, e processa tudo no dispositivo — sem round-trip para nuvem. O ciclo completo (entrada, inferência, ação) acontece localmente.

## Por que importa

- Privacidade real: dados de trabalho não saem da máquina. Isso muda o cálculo para times com política de confidencialidade rígida.
- Latência determinística: sem dependência de conexão, o agente responde em tempo consistente. Útil para automação de fluxos que não podem esperar rede.
- Autonomia: tarefas agendadas rodam mesmo com notebook fechado ou em trânsito. O agente opera como um serviço local, não um chat.

## Como começar

1. Confirme o hardware: notebook com AMD Ryzen AI Max (série 300) e Windows 11 atualizado.
2. Instale o runtime Portable Computer pela Microsoft Store ou portal de desenvolvedores.
3. Conceda permissões de acesso às pastas e apps que o agente precisará manipular.
4. Defina a primeira automação: uma tarefa simples (organizar downloads, resumir e-mails) para validar o fluxo antes de escalar.
