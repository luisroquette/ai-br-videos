# 590+ PROMPTS PRONTOS PARA CRIAR SITES QUE NÃO PARECEM FEITOS POR IA

Biblioteca com 590+ prompts prontos para gerar sites com visual menos genérico. Você filtra por tom ou mood — dark, luxe, technical, brutalist — copia o prompt e cola em qualquer modelo de código, como Claude, Cursor ou v0. Também inclui cenas 3D interativas e backgrounds gerados por IA. O material é atualizado diariamente, e há versão com MCP e código fonte completo.

## Por que importa
O problema não é gerar site com IA. É gerar site que parece ter sido feito por IA — aquele visual padronizado, com gradiente roxo e fontes default. Essa biblioteca ataca exatamente isso: curadoria de estilos e filtros de tom para você sair do padrão. Se você trabalha com desenvolvimento ou design, ter uma base de prompts organizada por estética economiza tempo e dá consistência.

## Como começar
Acesse o link da biblioteca. Escolha um prompt pelo filtro de tom ou mood. Copie o texto. Cole no Claude, Cursor, v0 ou qualquer modelo que aceite prompt. Se quiser integrar via MCP ou usar o código fonte, a opção está disponível no material.
