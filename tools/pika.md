# Pika

Pika é uma plataforma de criação de vídeo com IA que reorganiza o fluxo de trabalho. Em vez de escolher um modelo de difusão, você define o resultado: anúncio, filme, edição. A plataforma decide qual modelo usar. A interface foca no que você quer criar, não nos detalhes técnicos. Para anúncios, filmes ou edições, o fluxo é o mesmo: descrever a intenção e receber um vídeo.

## Por que importa

Para devs, isso remove uma decisão desnecessária da UI. A seleção de modelo é um problema de infraestrutura, não de produto. Pika trata essa complexidade como uma capa de abstração. Você não precisa conhecer as diferenças entre cada modelo de vídeo para usá-lo. Menos acoplamento a APIs específicas. Menos código para manter quando um modelo novo aparece. Esse tipo de abstração é o que permite integrar IA generativa em produtos reais sem que a lógica de negócio dependa de um vendor específico.
