# Muse

O Muse é um agente de IA da Meta. Na prática, é uma assistente de voz. A Meta veiculou o primeiro comercial nacional de TV para esse produto. A decisão coloca o agente no mesmo nível de um produto de consumo, não de um experimento de laboratório.

## Por que importa

É a primeira vez que um agente de IA aparece num comercial de TV nacional. Isso mostra que a Meta quer normalizar a interação por voz com IA para o público em geral. Para quem desenvolve, o ponto é estratégico: se o Muse for aberto via API ou SDK, vira um novo canal de automação. Se permanecer fechado no ecossistema da Meta, resta observar como ele evolui. De qualquer forma, o movimento indica que a disputa por interface de voz vai esquentar.
