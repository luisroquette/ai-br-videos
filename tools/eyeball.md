# Eyeball

Eyeball é uma skill customizada para o GitHub Copilot CLI, criada por Dan, diretor de Senior Corporate Counsel no GitHub. A skill faz o seguinte: quando a IA analisa um documento, ela captura screenshots das passagens relevantes e embute essas imagens na resposta. O usuário vê a análise e a prova visual lado a lado, sem abrir o arquivo original.

## Por que importa

Dan construiu Eyeball para revisar contratos com alto custo de erro. O time jurídico do GitHub adotou a ferramenta, e os advogados agora usam o terminal para checar cláusulas complexas. O padrão é direto: em vez de confiar na resposta da IA, você confere o trecho exato que gerou a conclusão. Isso transforma a IA em uma análise auditável, não em uma caixa-preta. A mesma lógica vale para qualquer documento em que confiança é crítica — não só no direito.
