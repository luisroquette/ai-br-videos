# null

Esse cookbook mostra como conectar um Claude Managed Agent ao Chat SDK da Vercel. Na prática, o agente ganha acesso a uma camada universal de chat — ou seja, você pode usar o mesmo agente em diferentes plataformas sem reimplementar integração nenhuma.

## Por que importa
Você escreve a lógica do agente uma vez e ele funciona em qualquer frontend que o Chat SDK suporte. Isso elimina retrabalho de adaptar o Claude para cada plataforma de chat separadamente. É integração limpa, sem acoplamento desnecessário.

## Como começo
Clone o repositório e siga o cookbook no link. Você precisa de uma chave de API da Anthropic e configurar o Managed Agent. Depois, basta importar o Chat SDK da Vercel e conectar ao agente — o passo a passo está no próprio exemplo.
