# PARE DE OTIMIZAR PROMPTS: O JEITO CERTO DE FAZER A IA TRABALHAR SOZINHA

O erro comum é tratar o prompt como o produto final. Você passa horas refinando instruções, mas o agente continua sendo uma função estática. O que separa um chatbot de um agente real é o loop: Planejar, Agir, Observar, Avaliar, Melhorar, Repetir. O prompt é só o ponto de partida, não o motor.

## Por que importa

Prompts otimizados são frágeis. Qualquer mudança no contexto quebra a resposta. O loop é resiliente: ele usa a saída da própria ação como dado de entrada para a próxima. Isso transforma a IA de um reprodutor de texto em um sistema que corrige a rota sozinho. Se você não avalia o resultado, não está construindo um agente, está chamando uma API com estilo.

## Como começar

Abandone a busca pelo prompt perfeito. Desenhe o ciclo.

1. **Planeje**: defina o objetivo final, não o passo exato.
2. **Aja**: execute a primeira ação concreta.
3. **Observe**: capture o retorno bruto (saída, erro, dado).
4. **Avalie**: compare o retorno com o objetivo.
5. **Melhore**: injete essa avaliação no próximo planejamento.
6. **Repita** até concluir.

Comece pequeno: um loop com 3 etapas. Só adicione complexidade quando o ciclo básico estiver estável. A evolução vem do feedback do sistema, não da sua escrita.
