# Cowork

O Cowork adicionou um navegador embutido ao Claude. Quando a tarefa envolve um site, o browser abre no painel lateral e o Claude navega, preenche formulários e conclui o trabalho sozinho.

## Por que importa

Isso elimina o vai-e-vem entre copiar URL, abrir no seu browser e colar o resultado de volta no chat. O fluxo vira uma coisa só: você pede, ele executa. Para automação de tarefas repetitivas em sites — preencher cadastros, consultar dados, baixar relatórios — é um passo concreto para agentes que resolvem sem supervisão constante.

## Como começar

Não há repo público identificado para o Cowork. O vídeo mostra o uso dentro da ferramenta, então o caminho é:

1. Acesse o Cowork e inicie uma sessão com Claude.
2. Peça uma tarefa que envolva navegação web (ex.: "preencha este formulário").
3. Observe o navegador abrir no painel lateral e acompanhe a execução.

Se você já usa o Cowork, teste com um site que exija login e múltiplos passos. É onde o navegador embutido faz diferença.
