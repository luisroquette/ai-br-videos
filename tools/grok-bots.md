# Grok Bots

Uma coleção de 170+ prompts prontos para o Grok, organizados por área de negócio: marketing, vendas, operações, produtividade. Cada "bot" é um prompt específico que você copia e cola no Grok para executar uma tarefa — sem código, sem configuração. O repositório é open source.

## Por que importa

Elimina o trabalho de engenharia de prompt para tarefas comuns de gestão. Em vez de criar do zero, você pega um bot testado e adapta. Acelera a adoção do Grok em fluxos reais de trabalho, especialmente para quem não quer perder tempo refinando prompts.

## Como começar

Acesse o repositório, navegue pela lista de bots (marketing, vendas, etc.), copie o prompt desejado e cole no Grok. Execute e ajuste se necessário. O ecossistema é aberto, então você pode contribuir com novos bots depois.
