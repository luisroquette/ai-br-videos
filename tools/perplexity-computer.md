# Perplexity Computer

O Perplexity Computer agora tem compute híbrido. A tarefa começa na nuvem e, quando precisa tocar em arquivos privados ou dados sensíveis, migra para um modelo local rodando no seu Mac. Nada de subir documento confidencial pra servidor de terceiro. Disponível hoje no app macOS.

## Por que importa

É um meio-termo prático entre latência de nuvem e privacidade local. Você usa a capacidade de um modelo grande pra parte pesada, mas o passo que envolve dado sensível roda na sua máquina. Sem VPN, sem confiar em política de retenção alheia. Para quem trabalha com código proprietário, contratos ou dados de cliente, isso resolve um problema real de compliance sem abrir mão de assistente.

## Como começar

- Atualize o app Perplexity para Mac (a versão atual já traz o recurso).
- Inicie uma tarefa normalmente — ela começa na nuvem.
- Quando a tarefa envolver arquivos locais ou dados sensíveis, o sistema muda pra execução local automaticamente.
- Confira se seu Mac tem modelo compatível (o recurso usa o hardware da máquina; não espere rodar em qualquer config).

Se o modelo local não for suficiente pra tarefa, ele continua na nuvem. Você controla o limite.
