# Codex

Codex é um agente de linha de comando da OpenAI que executa tarefas de programação direto no terminal. Você descreve o que quer e ele cuida do resto: instala dependências, escreve código, roda builds e lança simuladores. No vídeo, o fluxo é concreto: pedir a instalação do Xcode 27.1 beta, configurar o simulador iPhone Duo e mandar build + launch. O app aparece funcionando, sem que você toque uma linha de código.

## Por que importa

O salto não é autocompletar código, mas delegar o ciclo completo: setup, build, teste, launch. Para um dev, prototipar uma app mobile passa de dias a minutos. Para quem não programa, o terminal deixa de ser barreira — a IA absorbe o contexto de toolchain que antes era obrigatório.

## Como começar

1. Instale o Codex a partir do repositório oficial (github.com/openai/codex).
2. Rode o agente no terminal.
3. Descreva o app em linguagem natural, com o ambiente incluído: "instala Xcode 27.1 beta, configura o simulador iPhone Duo, faz o build e abre o app".
