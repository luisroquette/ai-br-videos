# Claude Code

Claude Code usado como organizador de conhecimento, não só como gerador de código. A ideia viralizou depois que o Andrej Karpathy sugeriu: apontar o Claude Code para uma pasta, jogar fontes dentro (artigo, transcrição, PDF) e deixar a ferramenta montar um wiki pessoal. O Claude lê o material, cria links e arquiva tudo num espaço vivo.

## Por que importa

O diferencial é o acúmulo. Cada fonte ingerida vira página linkada no wiki. Com o tempo, em vez de buscar em dez lugares, você faz uma pergunta e o Claude cruza tudo o que foi arquivado. Isso muda o fluxo: você não usa IA só para escrever código, usa para manter contexto do que leu e aprendeu. O retorno cresce conforme a base cresce.

## Como começar

1. Instale o Obsidian e crie um vault.
2. Abra o vault no Claude Code.
3. Cole a ideia do Karpathy e peça para ele construir a estrutura.
4. Ele deve criar três pastas: `raw` (fontes), `wiki` (páginas geradas) e um `CLAUDE.md` com as instruções.
5. Jogue uma fonte na pasta `raw` e diga "ingest this".
6. Faça perguntas sobre todo o material ingerido.

Funciona como um segundo cérebro consultável, sem depender de um serviço externo.
