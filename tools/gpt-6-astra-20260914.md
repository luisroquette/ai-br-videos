# GPT-6 Astra

O GPT-6 Astra é um agente de pesquisa criado por Percy Liang, professor de Stanford. Ele usa o modelo GPT-6 Astra como núcleo para processar artigos científicos em escala: analisa 11 milhões de papers por minuto, extrai descobertas, identifica contradições entre estudos e gera hipóteses novas automaticamente. O código está no repositório GitHub.

## Por que importa

A escala de leitura muda o tipo de problema que dá para atacar: revisão manual de literatura não acompanha o volume atual de publicações. Cruzar contradições e propor hipóteses automaticamente tira o cientista do trabalho braçal de leitura e coloca no desenho de experimentos. O valor de mercado foi reconhecido — o agente foi vendido por US$ 125.700 após 14 meses, com uma empresa pagando seis dígitos pelo acesso.

## Como começar

Acesse o repositório no GitHub e leia o README. O código está público. Para rodar localmente, siga as instruções de instalação do projeto.
