# Archify

Archify é um skill para agentes de IA como Cursor, Claude ou Codex. Em vez de gerar diagramas Mermaid ou imagens via IA, ele produz um HTML interativo com o tipo de diagrama que você pedir. Serve para documentar um sistema, explicar arquitetura em reuniões ou exportar para PNG e outros formatos.

## Por que importa

Mermaid é limitado para diagramas complexos. Imagens geradas por IA são bonitas, mas não editáveis. Archify entrega um HTML que você pode manipular, estilizar e integrar à documentação sem depender de ferramentas externas. O resultado é um artefato real, não uma imagem estática.

## Como começar

Adicione o skill ao seu agente (Cursor, Claude, Codex) seguindo as instruções do repositório. Depois, peça o diagrama descrevendo o que precisa — componentes, fluxos, dependências. O agente gera o HTML na hora. Exporte como PNG se precisar compartilhar fora do navegador.
