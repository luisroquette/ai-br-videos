# ChatGPT

O ChatGPT não é privado. A 404 Media revelou o "Project Lily": a OpenAI contrata centenas de pessoas para ler conversas reais de usuários. O trabalho é rotular, avaliar e ajustar os modelos. A Anthropic faz o mesmo com o Claude. Se você usava esses serviços achando que só máquinas viam o texto, não era bem assim.

## Por que importa

Se você usa ChatGPT para código, assuma o risco: lógica de negócio, trechos de sistema interno ou decisões de arquitetura podem passar por revisão humana. Nada de colar dados de cliente ou config em chat, mesmo com "não compartilhe" no prompt. "Não usar para treinar" não é o mesmo que "nenhum humano lê". Isso é exposição contratual e de compliance, não teoria da conspiração. O problema vale para o ChatGPT e para o Claude — privacidade é promessa de produto, não garantia técnica. Não existe flag no produto que elimine esse risco hoje.
