# memanto

O memanto é uma ferramenta open source que dá memória persistente a agentes de IA como Claude Code, Cursor e Codex. Ele salva o contexto das suas sessões, classifica com IA em 13 tipos de memória e recupera a informação relevante em menos de 90ms. Funciona com 20+ agentes e não depende de banco de dados vetorial. A instalação é direta: `pip install memanto`.

## Por que importa

Quem trabalha com agentes de IA conhece o problema: cada nova sessão começa do zero, e você precisa reexplicar o projeto, decisões e preferências. O memanto resolve isso sem infraestrutura extra. A classificação em 13 tipos de memória significa que o agente não busca só por palavra-chave — ele encontra o contexto certo pelo tipo de informação. Isso reduz atrito real no fluxo de trabalho.

## Como começar

1. Instale com `pip install memanto`.
2. Rode o comando de inicialização para conectar ao seu agente (Claude Code, Cursor, Codex, etc.).
3. Trabalhe normalmente. O memanto guarda o contexto da sessão automaticamente.
4. Na próxima sessão, o agente recupera o que precisa sem você reexplicar nada.

O projeto está no GitHub e já passou de 1.900 estrelas. Se você usa agentes de IA diariamente, vale testar.
