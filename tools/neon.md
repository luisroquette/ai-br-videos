# Neon

Neon é um modelo de linguagem treinado para análise de materiais. Foi desenvolvido em um laboratório de alta produtividade em Menlo Park. O laboratório funciona em um ciclo: experimentos geram novos dados, o modelo aprende com eles e indica os próximos testes. Para criar o Neon, a equipe usou 1.300 GPUs H200 e meses de dados experimentais próprios. O modelo passou por mid-training e reinforcement learning sobre uma base open-source. No benchmark interno de análise, ele superou o GPT-6 Astra. O foco são problemas de materiais: supercondutores, ímãs e semicondutores. O vídeo mostra imagens reais do laboratório.

## Por que importa

O resultado mostra que dados experimentais bem integrados valem mais do que escala bruta. Um modelo treinado com dados específicos superou um modelo muito maior em uma tarefa científica concreta. Isso tem implicações práticas: laboratórios podem montar seus próprios ciclos de descoberta sem depender de APIs fechadas ou de clusters gigantes. Para áreas como supercondutores, onde o espaço de busca é enorme, esse loop entre experimento e modelo acelera a decisão de o que testar em seguida.
