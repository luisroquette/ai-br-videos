# DRONES UCRÂNIANOS USAM IA PARA DESTRUIR CAMINHÃO RUSSO CHEIO DE FOGUETES

O vídeo mostra operadores de drones ucranianos usando um sistema de mira assistida por IA para atacar um caminhão que transportava foguetes de artilharia de 220mm para um BM-27 Uragan. O sistema identifica o alvo, provavelmente o rastrea e compensa o movimento, permitindo que o drone ataque com precisão. Não há repo público associado; é uma demonstração de campo.

## Por que importa

Este é um caso real de IA aplicada a sistemas de armas em ambiente de combate. A mira assistida por IA reduz a dependência do operador para calcular manualmente a trajetória ou manter o alvo sob estresse. Também mostra que a IA pode ser integrada a drones existentes, sem hardware dedicado. Para devs, é interessante ver como visão computacional e rastreamento de objetos funcionam em condições adversas: movimento, oclusões, alvos camuflados.
