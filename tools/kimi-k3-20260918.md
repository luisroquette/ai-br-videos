# Kimi K3

O Kimi K3 não é um chatbot. É um harness — a camada que controla ferramentas, contexto, permissões, memória e verificação em cada execução. O fluxo é único: um objetivo entra, o modelo processa, as ferramentas agem, o loop grava memória, um verificador valida e um humano aprova. O modelo é só uma peça dentro desse circuito.

O diferencial: o modelo é substituível. A mesma orquestração continua funcionando se você trocar o K3 por outro LLM. O harness segura o estado, as permissões e a lógica de verificação. O prompt perde importância. O sistema ganha.

## Por que importa

A camada valiosa deixou de ser o modelo ou o prompt. É o harness que mantém o comportamento quando o modelo muda. Com swarm fan-out de até 300 agentes, o mesmo esqueleto roda pesquisa, código e tarefas multi-etapa sem reconstruir orquestração a cada projeto. Migrar entre modelos deixa de ser um rewrite.

## Como começar

Clone o repositório. Leia o README para mapear os componentes do harness: ferramentas, verificador, camada de memória. Defina um objetivo simples e conecte um modelo compatível — não precisa ser o K3. Rode o loop e observe onde o harness intervém. Depois, troque o modelo de base e veja o que muda no comportamento. O que importa é o sistema, não a peça.
