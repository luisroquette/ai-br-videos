# WeKnora

WeKnora é um framework de conhecimento open source mantido pela equipe Weixin, do Tencent. Ele usa LLMs para entender documentos, fazer busca semântica e executar raciocínio autônomo. Você constrói assistentes que respondem com base nos seus docs, mostram as fontes usadas e podem acionar skills para gerar arquivos — com pré-visualização e download. A memória de longo prazo é opcional e controlada: o sistema sugere memórias, você aprova antes que elas entrem em uso. Dá para self-hostar e rodar skills em sandbox com limites de rede que você define.

## Por que importa

É uma opção sólida para quem precisa de respostas auditáveis em bases documentais grandes. A separação entre memória aprovada e execução em sandbox reduz o risco de comportamento imprevisível. Sendo open source e self-hosted, você mantém controle sobre dados e infraestrutura.

## Como começar

Acesse o repositório `Tencent/WeKnora` no GitHub. Leia a documentação para entender os componentes e requisitos. Siga as instruções de deploy para subir sua própria instância. Depois, teste com um conjunto pequeno de documentos antes de escalar.
