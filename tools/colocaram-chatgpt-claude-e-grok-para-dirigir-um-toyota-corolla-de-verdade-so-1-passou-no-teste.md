# COLOCARAM CHATGPT, CLAUDE E GROK PARA DIRIGIR UM TOYOTA COROLLA DE VERDADE. SÓ 1 PASSOU NO TESTE

Um experimento colocou ChatGPT, Claude e Grok para dirigir um Toyota Corolla real. Nada de simulação: volante, freio e acelerador entregues diretamente aos modelos. A interface era enxuta: três comandos — ver, virar, parar — acionados por aplicativos de chat comuns, como Codex, Claude Code e Cursor. Dos modelos testados, apenas um completou o percurso de cones. A maioria não passou da primeira curva.

## Por que importa

O teste não é sobre direção autônoma. É sobre até onde um LLM generalista controla um corpo físico com comandos mínimos. Se um modelo de propósito geral consegue isso com a infraestrutura de chat que já existe, o caminho para integrar LLMs a sistemas físicos fica mais curto — mas a taxa de falha mostra que ainda estamos longe de substituir modelos especializados.
