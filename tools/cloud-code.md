# Cloud Code

Cloud Code é um repositório que orquestra agentes autônomos de IA para executar tarefas de ponta a ponta: busca no Google Maps, geração de mockups, renderização de vídeos e envio de mensagens frias. O exemplo prático mostra um fluxo completo rodando em um MacBook, com custo de API de US$ 480 gerando US$ 18.800/mês — sem equipe e sem escritório.

## Por que importa

O valor aqui não é a mágica, é a arquitetura. Sete agentes trabalhando em paralelo, cada um com um papel específico, coordenados por um orquestrador. Isso é um padrão replicável para qualquer automação de vendas ou prospecção. Se você já brincou com agentes isolados, esse repo mostra como encaixá-los em um pipeline real, com custo controlado.

## Como começar

1. Clone o repositório e leia o `README` — ele detalha a stack e as dependências.
2. Identifique os agentes e o fluxo de dados entre eles. O ponto crítico é o orquestrador.
3. Substitua as credenciais de API e teste com um volume pequeno antes de escalar.
4. Rode localmente no seu MacBook — não precisa de infraestrutura cloud para validar o conceito.

O repo é um bom ponto de partida se você quer entender como agentes autônomos podem operar em conjunto, não apenas como demos isoladas.
