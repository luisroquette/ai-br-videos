# Muse

A Muse é a aposta da Meta para o que ela chama de agente pessoal. Em vez de só responder consulta, ela age: reserva viagem, envia e-mail, preenche formulário, negocia conta e faz compra. O processo continua mesmo depois que você fecha o app. Ela mantém contexto, entende o estado da tarefa e toma o próximo passo por conta própria. Roda numa nuvem dedicada, controlada pela Meta, e opera direto pelo WhatsApp. Está prevista para os óculos Meta AI.

## Por que importa

O que tem de concreto aqui é a mudança de assistente para agente de verdade. As ações citadas — negociar conta, comprar, enviar e-mail — exigem integração real com sistemas externos, identidade e um modelo de permissão. O fato de o trabalho continuar após fechar o app indica que foi desenhado para operar de forma assíncrona, não apenas responder em tempo real.

Receber esse agente pelo WhatsApp é decisão estratégica: o canal já existe, familiar, sem instalação. Rodar e a aplicação numa nuvem própria parece o caminho para auditar permissões. Antes de qualquer automação financeira, asetup de verificações — escopo, confirmação de pagamento, rastreio da transação — é pré-requisito.
