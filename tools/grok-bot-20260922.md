# Grok Bot

O Grok Bot atua como orquestrador. Em vez de alternar entre ChatGPT, Claude e Grok manualmente, você fala com um único bot — o Chief of Staff — que decide qual agente executa cada tarefa. O setup mostrado no vídeo usa Grok Build + Grok 4.6, Claude Code + Fable 5.1 e ChatGPT/Codex + GPT-6 Astra. Cada um mantém sua especialidade, mas todos compartilham memória persistente. Não há copy-paste entre chats.

## Por que importa

O ganho imediato é eliminar a troca de contexto. Você não repete o histórico para cada IA. O orquestrador conhece o estado geral e roteia a solicitação para o bot com a ferramenta certa. A integração com busca em tempo real do X e o Grok Imagine para mídia ampliam o escopo sem sair do fluxo. A interface cobre mobile, desktop e cloud desktop compartilhado, com voz embutida. É um padrão de arquitetura: um gateway central na frente de múltiplos agentes especializados.
