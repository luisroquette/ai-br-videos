# Grok Bot

O conceito: você não conversa com cada bot. Fala com um único Chief of Staff, que comanda ChatGPT, Claude e Grok. Ele roteia cada pedido para o agente certo: Grok Build + Grok 4.6, Claude Code + Fable 5.1, ChatGPT/Codex + GPT-6 Astra.

A memória é persistente entre todos. Sem copy-paste de contexto entre chats. A busca em tempo real do X já está conectada. Grok Imagine gera imagens e vídeos. O acesso funciona no mobile, desktop e uma cloud desktop compartilhada. Voz embutida.

## Por que importa

O problema resolvido é a fragmentação. Hoje você mantém contexto manualmente entre ferramentas. Com esse esquema, a IA faz o roteamento e carrega o estado. Você só fala com um ponto de entrada. Isso reduz fricção em fluxos que usam múltiplos modelos. A memória persistente é o diferencial prático: a conversa não recomeça do zero a cada troca de agente.
