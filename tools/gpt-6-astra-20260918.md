# GPT-6 Astra

O GPT-6 Astra é uma IA que gera cidades 3D completas a partir de descrições. No exemplo publicado, alguém construiu um mapa interativo de Seul com 25 distritos, 267 mil edifícios, modos dia/noite e fly-through por pontos turísticos. O tempo total: 43 minutos e  ️ 38 segundos. O código está no repositório oficial no GitHub.

## Por que importa

Isso reduz drasticamente o custo de criar ambientes urbanos para jogos, simulação e visualização. O resultado não é uma imagem estática — é um mapa navegável, com escala de cidade real. Automatizar esse processo abre caminho para prototipagem rápida de cenários urbanos, sem modelagem manual.



O repositório traz a implementação usada para gerar o mapa. Se você quer reproduzir ou adaptar para outras cidades, o ponto de partida é o link acima.
