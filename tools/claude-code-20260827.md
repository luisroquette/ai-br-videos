# Claude Code

Claude Code vira um segundo cérebro quando você o aponta para um diretório específico — tipo um vault do Obsidian — e joga material bruto lá: PDF, transcrição, artigo. O Claude parseia, conecta e integra tudo num wiki pessoal que cresce e fica mais afiado conforme você alimenta. A ideia central veio do Andrej Karpathy (cofundador da OpenAI) e o tweet sobre o workflow passou de 21 milhões de views. O relato do autor: implementar isso o ajudou a subir a renda mensal para US$ 13 mil há um ano.

## Por que importa

Não é sobre gerar código. É sobre transformar IA em infraestrutura de conhecimento que se retroalimenta. Você para de caçar informação solta e passa a ter um sistema que conecta pontos sozinho. O ganho é cumulativo: quanto mais você alimenta, mais útil fica. Para dev que vive de contexto, isso é diferencial direto em produtividade e, no limite, em renda.

## Como começar

1. Baixe o Obsidian e crie um vault novo.
2. Abra o vault no Claude Code (aponte o CLI para o diretório).
3. Jogue material bruto: PDF, transcrição, artigo.
4. Peça para o Claude parsear, conectar e integrar num wiki.
5. Repita. O sistema melhora com o volume.
