# Artemis

Artemis é um agente de IA open-source do Google que controla Android a partir de instruções em linguagem natural. Você escreve o que quer — "agendar um lembrete", "abrir o app e enviar mensagem" — e ele executa a automação completa no celular. No benchmark AndroidWorld, o agente passou de 99% de sucesso. Ele também integra com Codex, Claude Code e Antigravity, ou seja, não é uma ilha.

## Por que importa

Isso muda o nível de automação possível no Android. Hoje, automação exige scripts, Tasker ou acessibilidade na unha. Com Artemis, a camada de interpretação fica pronta: o modelo entende a intenção e opera a UI. Para quem trabalha com agentes de código, dá para plugar o Artemis como executor de tarefas no dispositivo. O celular deixa de ser um monte de apps e vira um ambiente operado por IA.

## Como começar

O Google abriu o código, então o primeiro passo é localizar o projeto — busque por Artemis no GitHub. Depois, verifique se o seu dispositivo Android atende os requisitos, já que o agente precisa de permissões de acessibilidade. Comece com tarefas simples, como abrir um app ou criar um alarme, antes de automações mais complexas.
