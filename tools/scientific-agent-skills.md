# Scientific Agent Skills

Scientific Agent Skills, do repositório K-Dense-AI/scientific-agent-skills, é um pacote open source que adiciona 163 skills científicos a agentes de IA. Com um único comando, o agente passa a acessar mais de 100 bases de dados — PubChem, ChEMBL, UniProt, ClinicalTrials.gov — e a executar tarefas de genômica, química computacional e docking molecular. Cada skill inclui documentação, testes e exemplos de uso. É compatível com Claude Code, Cursor, Codex e Antigravity.

## Por que importa

Não é um wrapper de API. É um conjunto de habilidades testadas que torna qualquer agente utilizável em pesquisa real. Para quem trabalha com bioinformática ou química, elimina o trabalho de construir integrações para cada base de dados. O projeto soma mais de 40 mil estrelas e é usado por mais de 190 mil cientistas — números que indicam adoção prática, não hype.

## Como começar

1. Instale com `npx skills add`.
2. Selecione os skills do seu domínio.
3. Use com Claude Code, Cursor, Codex ou Antigravity.

Os testes e exemplos do repositório mostram casos reais. Não é preciso configurar infraestrutura extra.
