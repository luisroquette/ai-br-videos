# ChatGPT 6 Astra

O caso que circulou mostra um dev usando Codex para gerar um plugin do World of Warcraft Classic. O pedido: criar um addon que listasse os agentes de IA em execução e notificasse quando terminassem. Em poucos minutos o plugin estava pronto e integrado ao jogo, exibindo mensagens dos agentes direto na interface do WoW.

## Por que importa

O exemplo não é sobre WoW. É sobre o fluxo: em vez de abrir o editor e escrever o addon manualmente, o dev descreveu o comportamento desejado em linguagem natural e o Codex gerou o código. Isso reduz o custo de prototipar ferramentas de integração. Também mostra agentes de IA sendo usados como interface para outros agentes — o jogo virou um painel de controle.

Mas vale manter o pé no chão. O vídeo mostra um demo, não um produto. Plugins gerados automaticamente podem ter problemas de manutenção e segurança. Para uso real, o código precisa ser revisado.
