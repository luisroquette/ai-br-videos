# Grok Bot

O Grok Bot, chatbot do X, virou host para outros agentes de IA. O vídeo mostra, em 4 minutos, como rodar Claude Code, Codex e Cursor dentro dele. O truque: conectar esses modelos ao Grok via API, transformando o chatbot em um terminal para múltiplos assistants.

## Por que importa

Isso elimina a necessidade de alternar entre interfaces. Você mantém o contexto da conversa no X e chama o agente certo para a tarefa: Claude para análise de código, Codex para automação, Cursor para edição. Para quem já vive no ecossistema do X, é um ganho real de fluxo. Menos troca de janela, mais trabalho feito.

## Como começar

O vídeo mostra o caminho básico: você precisa de uma chave de API dos modelos (Claude, OpenAI) e configurar o Grok Bot para apontar para esses endpoints. Não há repo oficial identificado — o autor provavelmente usou um script próprio ou uma configuração manual. Se quiser replicar, procure por "Grok Bot API integration" ou "custom model endpoint" na documentação do X. O processo é curto, mas exige familiaridade com APIs e variáveis de ambiente.

Se você já usa esses agentes, vale o teste. Se não, o vídeo serve mais como prova de conceito do que como tutorial completo.
