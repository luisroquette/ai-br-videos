# GROK BOT

GROK BOT unifica Claude Code, Codex e Cursor em um único fluxo controlado por agente. Em vez de você alternar manualmente entre assistentes de IA, ele coordena as chamadas, repassa contexto e gerencia o pipeline de codificação de forma automática. O resultado é um workflow onde um agente orquestra os outros, executando tarefas como revisão, geração e refatoração sem intervenção constante.

## Por que importa

O maior gargalo ao usar múltiplas ferramentas de IA é perder contexto entre elas — cada troca exige copiar, colar e reexplicar o problema. GROK BOT resolve isso centralizando a comunicação. Você ganha consistência e elimina o atrito operacional, especialmente em stacks complexos onde cada assistente tem um ponto forte (ex.: Claude Code para análise, Codex para geração, Cursor para edição). É um passo concreto para transformar ferramentas isoladas em um pipeline integrado.
