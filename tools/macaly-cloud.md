# Macaly Cloud

Macaly Cloud é uma plataforma que publica apps completos sem manter um agente de codificação próprio. A ideção é simples: você já paga por ChatGPT ou Claude, então eles escrevem o código. O Macaly fornece o que falta para colocar o negócio no ar — banco de dados, autenticação, hospedagem, domínio, pagamentos, SEO, analytics, segurança, geração de imagem e web scraping. O resultado é um fluxo direto: do prompt no seu LLM para um link público, sem tocar em infraestrutura.

## Por que importa

O custo mais alto de uma plataforma de vibe coding é o agente. O Macaly evita essa redundância: em vez de cobrar caro por mais um modelo no meio, ele integra os LLMs que você já usa e monetiza só a infraestrutura. Para um dev que quer validar uma ideia sem montar VPC, DNS e gateway de pagamento, isso reduz o atrito a quase zero.

## Como começar

1. Crie a conta no Macaly Cloud (grátis até 1º de outubro).
2. Gere o código do app no ChatGPT ou Claude no formato esperado pela plataforma.
3. Suba esse código no Macaly e conecte banco, auth e domínio.
4. Ajuste pagamentos, SEO e analytics nos painéis correspondentes.

Depois do período gratuito, o custo é fixo de US$ 10/mês. Sem porcentagem por uso de agente ou preço por request. Dá para focar no produto em vez da plataforma.
