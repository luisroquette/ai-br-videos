# Claude Code

Claude Code agora tem uma biblioteca oficial de prompts prontos. É gratuita. Os prompts são organizados por tarefa e por papel — planejamento, depuração, revisão de código, segurança, automação. Cada prompt vem com contexto explicando como e por que funciona. Não é uma coletânea aleatória feita por terceiro: é o mapa do que o Claude Code já sabe fazer, escrito pelos times da Anthropic que usam a ferramenta no dia a dia.

## Por que importa

Você deixa de escrever prompt do zero para tarefas repetitivas. Usa o que já foi testado internamente. O contexto embutido ajuda a entender o que está acontecendo — não é só copiar e colar, é aprender o padrão. Para quem vive de terminal, isso reduz fricção em tarefas chatas como revisão de segurança e debugging.
