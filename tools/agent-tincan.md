# Agent Tincan

Agent Tincan conecta seus agentes de IA numa rede privada Tailscale. Grok Bot, Muse, Instinct, Codex, Claude Code, ChatGPT e Claude passam a pedir ajuda uns aos outros. Sem portas abertas, sem tráfego saindo da sua rede. Open source, no GitHub.

## Por que importa

Hoje você é o CTRL+C/CTRL+V entre seus agentes. Muse faz ligações e tem acesso a Meta. Codex e Claude Code têm seu código. ChatGPT e Claude têm seus chats. Cada agente tem uma capacidade que os outros não têm.

Com o Agent Tincan, um agente pode acionar outro diretamente: peça ao Grok Bot para a Muse ligar para o restaurante, ou puxe um detalhe de um chat antigo do Claude sem abrir o app. Acabou o vai-e-vem manual de contexto.

A rede é sua. Tudo roda no seu Tailscale privado. Nada é exposto publicamente.

## Como começar

O setup é agent-first: cole uma mensagem no seu agente sempre ativo e ele configura o resto. Repositório: github.com/mvanhorn/agent-tincan.
