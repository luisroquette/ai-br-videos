# claude code workflow

Workflow de desenvolvimento em IA publicado por Garry Tan, presidente da Y Combinator. O repositório entrega uma cadeia de revisão completa para Claude Code: CEO → design → engenharia, tudo em um único comando. O setup detecta automaticamente qual CLI de IA você usa (Claude Code, Codex, Kiro, Factory ou Opencode) e configura o ambiente.

## Por que importa

Não é mais um prompt bonito. É o processo real de uma das pessoas mais influentes do Vale do Silício, empacotado como código. O `/plan` executa a cadeia de revisão completa — você não precisa mais orquestrar múltiplos agentes na mão. O `/ship` cuida do PR e do fechamento automático da issue no merge. Se você já perdeu tempo coordenando revisões de código com IA, isso elimina a camada de cola manual.

## Como começar

1. Clone o repositório: `git clone https://github.com/catlog22/Claude-Code-Workflow`
2. Rode o script de setup — ele detecta sua CLI instalada automaticamente.
3. Use `/plan` para iniciar a cadeia de revisão em qualquer issue ou tarefa.
4. Use `/ship` para abrir o PR e fechar a issue no merge.

O repositório tem 127k stars, o que sugere adoção massiva. Se você já usa Claude Code no dia a dia, esse workflow é um bom atalho para padronizar o processo sem reinventar o fluxo.
