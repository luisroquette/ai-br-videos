# LLM Fit

LLM Fit analisa o hardware da sua máquina e mostra quais modelos open-source de IA rodam localmente, sem custo. A ideia é direta: em vez de pagar assinatura mensal do ChatGPT, você usa o PC que já tem para executar modelos gratuitos. O vídeo demonstra um comando que faz a verificação e retorna as opções compatíveis com seu setup.

## Por que importa

Descobrir se um modelo roda no seu hardware normalmente é tentativa e erro: baixa, testa, trava, repete. LLM Fit elimina essa etapa ao cruzar as especificações da sua máquina com os requisitos dos modelos. Para dev, isso significa testar alternativas open-source sem custo recorrente e sem depender de API externa. Os dados ficam locais e você decide qual modelo faz sentido para o seu caso.

## Como começar

O vídeo mostra um comando que identifica o hardware e lista os modelos compatíveis. O fluxo é objetivo: rodar a verificação, conferir a lista retornada, escolher um modelo e executar localmente. Como o repositório não foi identificado, vale assistir ao vídeo para pegar o comando exato e os requisitos de instalação.
