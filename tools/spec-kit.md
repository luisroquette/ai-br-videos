# Spec Kit

Spec Kit é uma abordagem para programar com agentes de IA que troca o prompt vago por um fluxo de especificação estruturada. Em vez de pedir direto e torcer para o agente não quebrar nada, o Spec Kit força a IA a entender o projeto antes de tocar no código. O tweet mostra uma sequência de comandos: `/constitution` define regras e padrões, `/specify` descreve o que construir, `/clarify` resolve dúvidas antes de começar, `/plan` define arquitetura e stack, `/tasks` ordena as tarefas e `/implement` executa.

## Por que importa

O maior problema do código gerado por IA é a imprevisibilidade. O agente escreve rápido, mas sem contexto, e o resultado é código inconsistente ou quebrado. O Spec Kit ataca isso no início do processo: a especificação vira um contrato antes da implementação. Isso reduz retrabalho e torna o resultado mais previsível. Para quem trabalha com agentes diariamente, é a diferença entre rezar e ter um processo.

## Como começar

O tweet não traz detalhes de instalação, mas mostra o fluxo. Comece com `/constitution` para estabelecer as regras do projeto. Depois `/specify` para descrever o que quer construir. Use `/clarify` para a IA perguntar o que faltou. Siga com `/plan`, `/tasks` e `/implement`. Se você usa agentes de código, esse é um fluxo que vale testar num projeto pequeno.
