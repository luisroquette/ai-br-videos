# Claude

A Anthropic Academy liberou 22 cursos gratuitos sobre Claude. O material vai do básico ao avançado, organizado em trilha: começando por Claude 101 e Claude Cowork, passando por código (Claude Code, agentes, subagentes), plataforma (API, MCP, Bedrock, Vertex AI) e fechando com fundamentos de IA. A própria Anthropic divulgou a ordem recomendada no tweet original, então não existe desculpa para estudar tópico fora de sequência.

## Por que importa

É conteúdo oficial da Anthropic, não resumo de terceiros. A trilha resolve o problema de "por onde começar": você segue a ordem e evolui sem ficar escolhendo curso aleatório. E cobre tópicos avançados que normalmente ficam de fora de material introdutório, como MCP e subagentes.

## Como começar

1. Acesse academy.claude.com/courses/claude-101.
2. Faça o Claude 101 primeiro.
3. Siga a ordem do tweet: base → código → plataforma → fundamentos.
4. Avance para Claude Code 101 e os demais quando terminar.
