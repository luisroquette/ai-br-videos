# Project Suncatcher

O Project Suncatcher é a iniciativa do Google para testar TPUs em órbita. A ideia é simples: enviar um satélite de missão de teste para avaliar se os chips de IA aguentam radiação, temperatura e as condições do espaço. O objetivo final é descobrir se dá para hospedar infraestrutura de machine learning fora da Terra.

## Por que importa

Data centers terrestres consomem energia e água em escala absurda. No espaço, você tem energia solar praticamente infinita e resfriamento natural. Se os TPUs sobreviverem ao ambiente orbital, o próximo passo é pensar em clusters inteiros de IA operando fora do planeta — sem depender de rede elétrica ou refrigeração local. É uma aposta de longo prazo, mas os dados dessa missão vão definir se a arquitetura atual de chips aguenta o tranco ou se precisamos de hardware específico para ambiente espacial.

## Como começar

Não há repositório público ou código para testar agora. O projeto está em fase de coleta de dados com a missão de teste. Se você quer acompanhar o andamento, procure por "Project Suncatcher" nos canais oficiais do Google Research. Enquanto isso, a discussão relevante para devs é sobre resiliência de hardware: como seus modelos se comportariam com latência alta, radiação e recursos limitados? Vale simular esses cenários em workloads locais para entender onde o ML atual quebra fora do data center tradicional.
