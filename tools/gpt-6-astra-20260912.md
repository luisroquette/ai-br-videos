# GPT-6 Astra

O GPT-6 Astra é um agente de IA que converte linguagem falada em software interativo em tempo real. O diferencial está no resultado: em vez de texto genérico ou imagem estática, ele gera interfaces web funcionais a partir da descrição do usuário. No exemplo central do repositório, o usuário descreve um sintoma ou uma região de dor, e o Astra desenha, lança e exibe um modelo 3D da zona anatômica correspondente. Dentro da interface gerada, dá para ajustar amplitudes de movimento com sliders, alternar camadas de grupos musculares e consultar notas fisiológicas explicativas.

## Por que importa

A direção técnica apontada é a geração dinâmica de UI: o modelo sintetiza ferramentas de diagnóstico completas em runtime, não respostas pré-formatadas. Para dev, isso muda o contrato de interação com IA — o output vira aplicação utilizável, com estado, controles e dados embutidos. É um passo concreto na fronteira entre processamento de linguagem e entrega de software.

## Como começar

Acesse o repositório no GitHub e clone o projeto para a sua máquina. O ponto de partida é rodar o exemplo médico: descreva um sintoma e observe a geração da interface 3D. Depois, teste outras entradas de fala e veja como o modelo estrutura a UI dinâmica.
