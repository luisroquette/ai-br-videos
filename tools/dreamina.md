# Dreamina

O Dreamina é a ponta final de um pipeline que mistura geração 3D com renderização por IA. No fluxo mostrado, GPT-6 Astra gera a geometria no Blender; o Clay Renderer Plugin envia o modelo de argila direto do Blender para o Dreamina. Lá, o Seedance 2.5 transforma o modelo em footage final—mantendo câmera e layout travados, adicionando apenas o visual. Ou seja: você não precisa refazer a cena;a IA só aplica o acabamento.

.



## Por que importa

O ganho é eliminar o retrabalho. O layout e a câmera ficam fixos; a IA cuida do look. Isso separa a etapa de modelagem da etapa de renderização, e cada uma pode usar a ferramenta certa. Além disso, Seedance 2.5 e  ️2.0 estão com preço competitivo, o que reduz a barreira para testar o fluxo. Para quem já trabalha com Blender, o plugin diminui o atrito entre o modelo 3D e o vídeo final. 



## Como começar

1. Modele a geometria no Blender—no vídeo, o GPT-6 Astra faz essa parte. 
2. Use o Clay Renderer Plugin para enviar o modelo de argila para o Dreamina. 
3. No Dreamina, rode o Seedance 2.5 para gerar o footage final. 
4. Mantenha câmera e layout como estão—a IA só altera o visual.
