# LLMagnet

LLMagnet é uma solução para WordPress que trata um problema específico: aparecer nas respostas de modelos de IA, não só no Google. Ela monitora a atividade de bots de IA no seu site, mede o quanto você é citado em ferramentas como ChatGPT, Claude, Gemini e Perplexity, gera o arquivo `llms.txt`, melhora dados estruturados e permite conexão com clientes de IA via MCP.

## Por que importa

O Google ainda é relevante, mas uma parcela crescente de usuários pede recomendações direto para assistentes de IA. Se o seu site não é mencionado por esses modelos, você fica invisível num canal que já está gerando tráfego de referência. LLMagnet ataca isso com métricas e integrações práticas: você sabe se os bots estão te visitando, o que eles leem e como ajustar o conteúdo para ser usado como fonte.

Sem esse tipo de dado, você está otimizando para um mecanismo de busca que já não é o único gatekeeper. LLMagnet não promete rankeamento — ele dá visibilidade sobre como os LLMs enxergam seu site.
