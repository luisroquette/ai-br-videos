# Claude

O vídeo é um guia pessoal de uso do Claude em tarefas de marketing e negócio. A premissa: prompts comuns desperdiçam boa parte do potencial do modelo. O autor defende que, em vez de frases vagas, você deve usar comandos de barra específicos para acionar comportamentos determinados — os exemplos citados são `/reframe`, para trocar de perspectiva, e `/devil`, para forçar uma análise contrária. No total, o guia reúne 99 desses atalhos. Não é plugin, não é configuração avançada: é mudança de vocabulário na conversa.

## Por que importa

A lógica faz sentido para quem usa LLM como ferramenta de trabalho. Saída ruim quase sempre é consequência de entrada ambígua. Comandos objetivos reduzem o espaço de interpretação do modelo e tornam a resposta mais previsível — a mesma relação que um dev tem com flags de CLI. O recorte do vídeo é de marketing e negócios, mas o princípio se aplica a código, documentação e análise. Ninguém precisa decorar os 99 comandos; o valor está em usar curadoria para eliminar o vai-e-vem de prompts mal formulados.
