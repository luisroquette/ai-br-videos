# ID-V2V

ID-V2V é uma técnica de video-to-video lançada pela Netflix que troca o visual de um vídeo inteiro — estética, luz, acabamento — sem mexer no que importa: o rosto da pessoa, a atuação e o sync de lábios continuam intactos. O modelo opera sobre keyframes e ainda corrige automaticamente keyframes ruins, o que reduz retrabalho manual. O código está no repositório da Eyeline-Labs.

## Por que importa

Para quem trabalha com pós-produção ou geração de vídeo, isso ataca um gargalo específico: você não precisa re-renderizar ou refazer a captura de performance para mudar a estética de uma cena. A preservação de identidade e de lip sync mantém a atuação original, mesmo com o vídeo re-estilizado do início ao fim. E o auto-correct de keyframes elimina parte do trabalho sujo de limpar frames ruins na mão.

## Como começar

O código está no repositório da Eyeline-Labs e o tweet original aponta para a demo. Clone o repo, leia o README para as dependências e rode a demo com um vídeo de teste. Depois, aponte o script de inferência para o seu próprio vídeo e compare antes/depois. O caminho mais rápido é reproduzir o demo antes de tocar em qualquer parâmetro.
