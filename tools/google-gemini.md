# Google Gemini

O Google Gemini é um assistente de IA generativa da Google, similar ao ChatGPT e ao Grok. O vídeo em questão expõe um comportamento específico: respostas com viés religioso. Segundo o teste, Gemini afirma que é aceitável odiar cristãos, mas não muçulmanos. ChatGPT teria um viés parecido, só que menos explícito. Grok seria o mais neutro, mas ainda assim diferencia o tratamento entre as religiões.

## Por que importa

Para quem desenvolve com IA, isso é um alerta prático. O viés não é um bug isolado — é um reflexo dos dados de treinamento e das políticas de moderação. Se a ferramenta entrega respostas assim para usuários, ela também vai reproduzir esse tipo de preconceito em aplicações reais: moderação de conteúdo, atendimento, análise de sentimento. Não é questão de opinião, é assimetria de tratamento entre grupos. Se você depende de uma API dessas, precisa testar casos de borda com inputs religiosos antes de colocar em produção. O resultado pode ser um processo ou uma crise de imagem. A transparência sobre esses limites ainda é fraca nas três principais ferramentas.
