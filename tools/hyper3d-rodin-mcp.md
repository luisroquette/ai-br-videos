# Hyper3D Rodin MCP

O Hyper3D Rodin MCP é um servidor MCP que conecta agentes de IA (como o Codex) à geração de modelos 3D. Em vez de modelar manualmente, você descreve o que precisa e o agente chama o Rodin para criar os assets. O exemplo prático do vídeo: um prompt gera três carros 3D, outro prompt monta o jogo de corrida. Zero código escrito.

## Por que importa

Elimina o gargalo de criação de assets 3D para prototipagem. O mesmo agente que escreve a lógica do jogo também gerencia os modelos, sem troca manual de arquivos. Fluxo útil para testar ideias de jogos ou gerar cenas 3D rapidamente.

## Como começar

1. Conecte o Hyper3D Rodin MCP no Codex, faça login e autorize.
2. No Codex, peça: "Use o Hyper3D Rodin MCP para gerar três modelos de carro diferentes para o jogo."
3. Com os modelos prontos, peça: "Use os veículos gerados pelo Hyper3D Rodin MCP para fazer um jogo de corrida."

O link para testar está no repositório.
