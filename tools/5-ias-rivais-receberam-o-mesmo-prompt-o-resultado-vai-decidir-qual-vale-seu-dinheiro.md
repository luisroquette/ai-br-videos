# 5 IAs RIVAIS RECEBERAM O MESMO PROMPT. O RESULTADO VAI DECIDIR QUAL VALE SEU DINHEIRO

Cinco modelos de IA receberam o mesmo prompt: criar uma landing page de relógio de luxo. Sem retry, sem edição manual. O resultado está publicado para comparação direta. Fable 5.1, GPT-6 Astra, DeepSeek v4.1 Flash, GLM 5.3 Flash e Qwen3.8 Flash Next — cada um gerou uma página completa, do zero, e o autor do teste já aponta seus favoritos.

## Por que importa

Benchmark de modelo costuma medir conhecimento teórico. Aqui a régua é outra: capacidade de gerar frontend utilizável, com bom senso visual e código limpo, em uma única passada. Para quem usa IA como ferramenta de prototipagem, essa é a diferença que importa. Dá para ver na prática quais modelos acertam hierarquia visual, espaçamento e acabamento sem intervenção humana.

## Como começar

Acesse a demo ao vivo no link do repositório. Compare as cinco versões lado a lado. Inspecione o HTML e o CSS de cada uma no navegador para avaliar a estrutura gerada. Se quiser repetir o teste, use o mesmo prompt para cada modelo e compare os resultados — sem retoques.
