# AlphaGenome Atlas

O AlphaGenome Atlas é um banco de dados aberto com 1 petabyte de informação genômica. Ele mapeia os efeitos moleculares de todas as 9 bilhões de variações de uma única letra no DNA humano. Não é um LLM — é uma base de dados consultável, com scores de mutação unificados (AVI) e acesso via portal web ou API.

## Por que importa

Para quem trabalha com bioinformática ou genômica, é um recurso direto: em vez de rodar simulações caras ou depender de modelos proprietários, você consulta um índice público e padronizado. A escala é nova — 9 bilhões de variantes cobertas, com um score único para cada uma. Isso reduz o custo de entrada para análises de variantes, especialmente em pesquisa clínica ou populacional.

## Como começar

1. Acesse o portal web pelo link do repositório.
2. Use a busca para consultar variantes específicas ou faça download de subsets.
3. Para integração em pipelines, use a AlphaGenome API — a documentação está no site.
4. Se precisar de automação, há um agente (agent skill) disponível para tarefas repetitivas.

Sem firula: é uma base de dados grande, bem organizada e com acesso aberto. O resto é com você.
