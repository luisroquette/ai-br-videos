# Jev

Jev é um sistema que distribui tarefas entre vários modelos de IA. Em vez de mandar todo prompt ao modelo mais caro, ele avalia a dificuldade. Tarefas simples vão a modelos baratos. Raciocínio complexo escala ao modelo top. O tweet mostra que isso deixa o sistema literalmente mais rápido: o modelo barato responde rápido, e o caro não se atasca com trabalho trivial.

## Por que importa

A maioria dos agentes de IA ainda envia tudo a Claude Code. Isso ignora uma realidade: a maior parte das chamadas em produção são simples. Pagar o preço máximo por um rename de variável ou uma resposta de lookup é absurdo. Jev ataca exatamente esse problema. Manda o fácil ao barato, reserva o caro para o que exige raciocínio profundo. Para devs que constroem agentes com uso real, isso é arquitetura que escala: menos latência, menos custo, mesma qualidade. E o modelo caro fica disponível quando realmente importa.
