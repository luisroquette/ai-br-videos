# Claude Opus 5

Claude Opus 5 assistiu a uma animação e deduziu sozinho que se tratava de pontos matematicamente posicionados em p5.js. Depois disso, reescreveu o código para gerar uma versão de lula. Sem prompt detalhado, sem explicação de contexto. Só observou o resultado visual e inverteu o processo.

O que importa aqui não é o exemplo específico, mas o método. A ferramenta está reconstruindo lógica a partir de pixels. Isso muda o fluxo de trabalho para quem prototipa: em vez de descrever o que quer, você mostra algo funcionando e pede uma variação. O modelo interpreta a estrutura matemática por trás do visual e reaproveita isso em código novo.

## Por que importa

- Elimina a etapa de documentar o comportamento esperado. O código vira consequência da observação.
- Acelera iteração em projetos visuais. Você testa uma direção, e a IA propõe outra variante com a mesma base lógica.
- Serve como ferramenta de ensino reversa: dá para entender como uma animação foi construída pedindo para o modelo explicar o que viu.

## Como começar

Se você já usa p5.js ou Processing, o caminho é direto: rode uma animação simples, capture um frame ou um GIF curto, e peça para o Claude Opus 5 analisar a estrutura matemática e gerar uma variação. O resultado tende a ser mais preciso se a animação tiver padrões visuais claros (movimento periódico, posições calculadas, cores derivadas de fórmulas).
