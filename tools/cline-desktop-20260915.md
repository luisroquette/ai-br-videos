# Cline Desktop

O Cline Desktop é um app open-source para Mac e Windows que dá acesso a modelos open-weight sem exigir chave de API. Modelos como DeepSeek V4 Flash, GLM 5.3 Flash e Laguna S 2.1 estão disponíveis direto no app. No exemplo do vídeo, o DeepSeek V4 Pro foi usado para criar um harness de avaliação para um pipeline de ML. Com um único prompt, o modelo verificou o ambiente, identificou pacotes disponíveis e gerou um pacote `ml_eval` completo, com 9 arquivos e testes passando. O ponto de partida era uma pasta vazia.

## Por que importa

Sem API key, sem custo por token. Isso remove a barreira para testar modelos open-weight em tarefas reais. O modelo não só escreve código: ele explora o ambiente, checa dependências e entrega algo testado. Para prototipar ferramentas internas ou validar uma ideia, o fluxo é muito mais curto.

## Como começar

1. Baixe o Cline Desktop para Mac ou Windows em cline.bot/desktop.
2. Instale e abra o app.
3. Escolha um modelo na lista (DeepSeek V4 Flash, GLM 5.3 Flash etc.).
4. Aponte para uma pasta e descreva a tarefa em linguagem natural.
