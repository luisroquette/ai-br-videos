# GPT Image 2.5

GPT Image 2.5 gera imagens boas, mas extrair resultado de agência exige método. O autor deste material gastou 15 horas e US$ 478 em créditos de API para chegar lá. Agora ele disponibiliza o workflow completo: 5 agent skills para reconstrução, edição, engenharia reversa, mistura de referências e verificação de resultados. Inclui também guia visual de 50 páginas, 95 prompts salvos, 44 estudos ilustrados, mapas de imagem interativos, JSON reutilizável, ferramentas Python, imagens de origem e logs de reparo.

## Por que importa

O problema não é gerar uma imagem — é gerar consistentemente, com controle e sem retrabalho. O material entrega isso como sistema, não como dica solta. Os agent skills são instaláveis em Codex ou Claude Code, então o fluxo vira parte do seu ambiente de trabalho. O custo de tentativa e erro já foi pago por alguém; você pula a fase de descobrir o que funciona.

## Como começar

1. Baixe os skill packs e o código-fonte (incluídos no material).
2. Instale os agent skills no Codex ou Claude Code.
3. Adicione suas imagens de referência — o workflow aceita inputs próprios.
4. Use os prompts da biblioteca pesquisável como ponto de partida.
5. Consulte os antes/depois e logs de experimento para calibrar expectativas.

Sem mistério: é um pacote de engenharia de prompt com ferramentas de apoio, pronto para rodar.
