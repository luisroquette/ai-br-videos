# Buzzy

O Buzzy liberou o GPT Image 2.5 por 7 dias, sem limite de geração. Segundo o anúncio, é o modelo de imagem mais forte da OpenAI até agora. A proposta: detalhes mais nítidos, texto renderizado com mais precisão e respostas melhores a prompts complexos. Durante a janela promocional, você pode gerar quantas imagens quiser.

## Por que importa

Acesso ilimitado a um modelo de imagem topo de linha é raro. Normalmente você lida com cotas ou pagamento por geração. Com 7 dias livres, dá para testar o modelo em cenários reais: assets para interface, thumbnails, imagens com texto embutido. Se a melhoria na renderização de texto se confirmar, isso resolve um dos gargalos clássicos de IA generativa.

## Como começar

Acesse o link do tweet. Selecione o GPT Image 2.5 na interface do Buzzy. Comece a gerar.
