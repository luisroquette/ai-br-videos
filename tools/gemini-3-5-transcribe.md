# Gemini 3.5 Transcribe

O Gemini 3.5 Transcribe é um modelo de API da Google focado em transcrição de áudio. Ele converte fala em texto e tenta capturar a intenção por trás dela. O diferencial está no suporte a múltiplos falantes simultâneos e na detecção automática de mais de 85 idiomas, sem configuração prévia.

Também há suporte a vocabulário customizado. Isso permite adaptar o modelo para jargões técnicos, nomes próprios ou termos específicos do seu domínio, que normalmente quebram transcrições genéricas.

## Por que importa

Se você já lutou com diarização de falantes (saber quem disse o quê) ou com áudios multilíngues, esse modelo resolve dois problemas de uma vez. A detecção de idioma automática elimina a necessidade de pipelines de detecção separados. O vocabulário customizado é útil para áreas como medicina, direito ou suporte técnico, onde a precisão em termos específicos é crítica.

## Como começar

1. Acesse o Google AI Studio e crie uma chave de API.
2. Envie um arquivo de áudio para o endpoint do modelo.
3. Teste com um áudio que tenha múltiplos falantes para ver a diarização em ação.
4. Se tiver jargões, use o parâmetro de adaptação de vocabulário e re-teste.

A API está disponível no AI Studio e no Gemini Enterprise. Também dá para testar no app do Gemini para macOS ou no Rambler para Android.
