# Fable 5.1

Fable 5.1 é o novo modelo da Anthropic, da família Mythos, agora disponível no GitHub Copilot. Ele é desenhado para tarefas de codificação longas, pesquisa profunda de codebase e workflows agenticos complexos. Nos testes, mostrou desempenho sólido nesses cenários, o que sugere que ele mantém contexto e executa múltiplas etapas sem perder o fio.

## Por que importa
Quem usa agentes de código sabe o custo de interromper uma tarefa para reorientar o modelo. Fable 5.1 reduz esse atrito ao sustentar sessões longas e lidar com investigações profundas em código existente. Isso é útil para refatorações grandes, debugging de legado ou automação de fluxos com várias etapas.

## Como começar
O modelo está disponível no app do GitHub Copilot, na CLI e no VS Code. Para usar, abra as opções de modelo do Copilot e selecione Fable 5.1. Ele já está em disponibilidade geral, então é só escolher e testar.
