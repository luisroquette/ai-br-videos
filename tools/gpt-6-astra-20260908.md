# GPT-6 Astra

GPT-6 Astra é uma ferramenta de geração de vídeo por IA que propõe um fluxo de trabalho diferente: em vez de digitar um prompt e esperar o resultado final, você desenha o shot antes. O repositório no GitHub mostra a integração com o CapCut PC. O objetivo é fazer a IA operar com linguagem de cinema, não apenas com conteúdo gerado.

## Por que importa

O diferencial está na etapa de planejamento. Você decide enquadramento, movimento e composição antes de gerar o quadro. Isso aproxima o controle criativo de quem está operando, em vez de depender de sorte no prompt. O workflow vira direção de fotografia, não apenas geração de imagens. Para quem já trabalha com vídeo, a mudança é prática: mais intenção por trás de cada cena.

## Como começar

Acesse o repositório no GitHub e leia a documentação disponível. Instale o GPT-6 Astra e abra o CapCut PC. No primeiro teste, não vá direto ao prompt final. Defina o shot: o que aparece, de onde a câmera olha, como o movimento acontece. Depois, gere o vídeo e edite no CapCut. Compare o resultado com um fluxo de prompt direto e veja a diferença.
