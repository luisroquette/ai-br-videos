# COMO TRANSFORMAR QUALQUER CODIGO DO GITHUB EM UM PROMPT PRONTO PARA COPIAR

Transformar um repositório do GitHub em um prompt pronto para copiar é um truque útil para quem quer reutilizar código sem reescrever tudo do zero. A ideia é simples: em vez de ler linha por linha, você extrai a estrutura, os padrões e as funcionalidades principais do projeto, e condensa isso em um texto que uma IA consegue interpretar e reproduzir. O vídeo mostra esse fluxo, mas não revela qual repositório foi usado — o método serve para qualquer projeto público.

## Por que importa

Isso acelera a engenharia reversa e a reutilização de código. Em vez de gastar horas navegando em pastas e arquivos, você obtém um resumo executável que pode ser colado em um chat de IA para gerar uma versão funcional ou para entender a lógica por trás. É uma ponte entre leitura e ação, especialmente útil para aprender com projetos grandes ou para prototipar rapidamente a partir de bases existentes.

## Como começar

1. Clone o repositório localmente: `git clone <url>`.
2. Use uma ferramenta de análise estática (ou até um script simples) para listar a árvore de arquivos e extrair os nomes de classes, funções e dependências principais.
3. Escreva um prompt descrevendo a arquitetura, os módulos e o propósito de cada parte, com base nessa extração.
4. Cole o prompt em um modelo de linguagem (como ChatGPT ou Claude) e peça para gerar o código ou explicar o funcionamento.
5. Ajuste o prompt com detalhes específicos que você notar, como bibliotecas usadas ou padrões de design.

O resultado não é uma cópia exata, mas um ponto de partida que economiza tempo e esforço.
