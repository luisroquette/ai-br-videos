# Claude

O Claude é o modelo de linguagem da Anthropic. No vídeo, o CEO Dario Amodei explica por que as salvaguardas de biologia do modelo são rígidas. Estudantes de biologia reclamam das restrições e fazem piadas. Ele responde: prefere ser zoado a descobrir que o Claude foi usado para matar pessoas. A fala é um resumo direto do trade-off de segurança que a empresa adota.

## Por que importa

Para quem desenvolve com IA, a declaração mostra uma decisão de design explícita: segurança é uma feature, não um efeito colateral. A Anthropic aceita perder usos legítimos para reduzir risco de abuso. Na prática, prompts relacionados a biologia podem ser bloqueados ou exigir verificação extra. Quem trabalha com APIs precisa entender essas políticas antes de planejar o produto. Não é censura aleatória; é uma escolha consciente de trade-off.

## Como começar

Leia a política de uso aceitável da Anthropic. Verifique se o seu caso de uso envolve áreas restritas. Se envolver, prepare documentação e contexto para avaliação. Teste o modelo com inputs reais para mapear onde as salvaguardas atuam. Isso evita surpresa no meio do desenvolvimento.
