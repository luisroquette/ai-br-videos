# Video Use

Video Use usa Claude para editar vídeo de forma automática. Você joga os archivos em uma carpeta, e a ferramenta corta clips, remove muletillas e silencios, gera legendas, aplica corrección de cor, adiciona animações e renderiza o resultado final. Nada de timeline manual. É open source e gratuito.

## Por que importa

Para devs que producem conteúdo, isso elimina o trabalho braçal da edição. Não precisa abrir Premiere ou DaVinci para cortar silencios ou ajustar cor. Basta uma folder e um modelo de linguagem. E como é open source, você pode adaptar os prompts ou a lógica ao seu pipeline.

## Como começar

Clone o repo (link abaixo). Leia o README para configurar o ambiente. Você vai precisar de uma API key para Claude. Coloque seus vídeos na carpeta indicada e execute o script principal. A partir daí, o processo roda sozinho.
