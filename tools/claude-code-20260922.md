# Claude Code

O tweet resume: assistir um engenheiro da Anthropic ensinando a construir prompts faz você perceber que estava usando o Claude Code no automático. A aula mostra que prompt não é frase solta — é um contrato de contexto. O jeito "mono" de usar: digitar uma instrução e esperar mágica. O jeito certo: dar contexto estruturado, exemplo de saída, restrições explícitas.

## Por que importa

A diferença entre um prompt ruim e um bom não é tamanho. É clareza. O Claude Code tem acesso ao seu repositório, mas não sabe o que você quer se você não disser. Um engenheiro demonstrando na prática mostra que prompts bem construídos reduzem idas e vindas, alucinação e retrabalho. Você deixa de depurar a resposta da IA e passa a revisar um resultado que já veio perto do que você pediu.

## Como começar

Assista à talk inteira antes de testar. Depois, pegue um prompt que você já usa no dia a dia e reescreva seguindo a estrutura que o engenheiro mostra: papel, contexto, entrada, saída esperada, restrições. Compare o antes e o depois. Não precisa decorar nada — só observar como ele quebra o prompt em partes. Aí aplica no seu próximo ticket.
