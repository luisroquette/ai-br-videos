# Model Hardware Standard

O Model Hardware Standard (MHS) é um padrão aberto proposto pela Anthropic para que agentes de IA controlem equipamentos físicos de forma segura e previsível. Em vez de cada integração reinventar a roda — e os riscos — o MHS define uma interface comum entre o modelo e o hardware. O foco inicial é laboratórios de pesquisa científica e linhas de manufatura avançada.

## Por que importa

Hoje, conectar um LLM a um braço robótico ou a um espectrômetro exige adaptadores ad hoc e validação manual de segurança. O MHS ataca isso com uma camada de abstração que padroniza comandos, limites operacionais e states de erro. Para quem trabalha com automação de laboratório ou fábrica, isso significa menos tempo escrevendo middleware e mais tempo testando loops de decisão do agente.

## Como começar

Acesse o research preview no link oficial da Anthropic. O repositório contém a especificação inicial e exemplos de implementação. Ideal para quem quer experimentar com controle de hardware via API de agente sem precisar construir toda a stack de segurança do zero.
