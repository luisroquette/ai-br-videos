# FERRAMENTA DE IA GRATUITA ACABA COM INDUSTRIA DE CORTE DE VÍDEO DE US$49/MÊS

OpenShorts é um cortador de vídeo open source que promete eliminar a assinatura de serviços como OpusClip e Flowjin. Ele roda localmente (self-hosted) e usa IA para detectar os melhores trechos de vídeos do YouTube ou arquivos locais. Sem marca d'água, sem limite de uso imposto pela ferramenta.

## Por que importa

O custo real é o seu próprio modelo de IA. Você pluga uma chave de API (Claude, Gemini, etc.) e o corte é processado por ela. Isso significa que o custo por vídeo é o que você já paga pelo modelo, não uma taxa fixa mensal de US$49. Para quem já usa API de IA no fluxo de trabalho, o preço marginal é praticamente zero.

O código aberto também permite auditar o que a ferramenta faz com seus vídeos e adaptar o pipeline de corte para o seu caso de uso. Não é uma caixa preta SaaS.

## Como começar

1. Clone o repositório `https://github.com/mutonby/openshorts`.
2. Configure sua chave de API de um provedor de IA suportado (o guia menciona Gemini, mas a ferramenta aceita outros modelos).
3. Rode o projeto localmente — o README do repositório tem as instruções de instalação.
4. Cole um link do YouTube ou aponte para um arquivo local e deixe a IA selecionar os cortes.

O detalhe: precisa de uma conta paga do modelo de IA que você escolher. O autor menciona que estudantes têm acesso gratuito ao Gemini por um ano, o que reduz o custo inicial para zero nesse cenário.
