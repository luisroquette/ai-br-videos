# A IA ROBÔ QUE APRENDE A FAZER PANQUECAS SÓ DE ASSISTIR UM VÍDEO

O modelo robótico S1 demonstra aprendizado por contexto em tarefas de manipulação. Ele assiste a um único vídeo de uma tarefa — como fazer uma panqueca — e executa a ação sem fine-tuning. Não é uma skill pré-programada nem um caso de generalização clássica: é o modelo resolvendo uma tarefa fora da distribuição de treino, só com o exemplo no prompt.

## Por que importa

Isso muda a forma de pensar sobre robótica. Em vez de coletar dados massivos para cada nova tarefa, o modelo pode absorver uma demonstração e executar na hora. É o mesmo salto que vimos de BERT para GPT-3 em linguagem, mas aplicado a controle físico. Se isso se sustentar em escala, o custo de adaptar um robô a uma nova tarefa cai drasticamente — de semanas de coleta de dados para minutos de vídeo.

## Como começar

Não há repositório público identificado ainda. Se você trabalha com robótica, vale acompanhar a publicação do S1 e os resultados de manipulação que a equipe promete liberar. Para testar o conceito em menor escala, o modelo de locomoção com aprendizado por contexto (lançado em 2025) é um ponto de partida mais acessível.
