# Nothing OS 5.0

Nothing OS 5.0 é a nova versão do sistema operacional da Nothing, anunciada para o Phone (3). O foco é reduzir o ruído digital: redesenho visual, home screen adaptativa e widgets com novas funções. A empresa também promete animações mais rápidas e suaves, além de integrar as ferramentas de IA "Essential" — que já existiam, mas agora aparecem mais maduras. A base é o Android 17.

## Por que importa

O diferencial aqui não é a lista de features, mas a direção: a Nothing está tratando IA como camada de filtragem, não como assistente genérico. O conceito de "filtrar o caos digital" é concreto — menos notificações irrelevantes, mais priorização do que importa. Para quem trabalha com mobile, é um case interessante de como uma OEM pequena está usando IA para justificar um sistema próprio em vez de só empilhar recursos do AOSP.

## Como começar

O Open Beta começa amanhã para o Phone (3). Se você tem o aparelho, o caminho é o programa beta oficial da Nothing — normalmente via configurações do sistema ou app de suporte. Não há repo público ou SDK específico para essa versão até o momento.
