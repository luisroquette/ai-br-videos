# Agents API

O Agents API é a tentativa da OpenAI de tirar da sua mão a parte operacional de agentes de IA. Em vez de montar orquestração, controle de sessões longas e gerenciamento de contexto, você recebe isso pronto, usando o harness do Codex como base. O agente roda em cloud, gerenciado pela OpenAI. Você fica com a parte que diferencia o seu agente. Está em beta público.

## Por que importa

O gargalo de agentes não é o modelo — é o esqueleto ao redor. Lidar com estado, retomar execuções e manter contexto consumia tempo antes de qualquer feature. Se a OpenAI sustenta essa camada, o custo de entrada cai. Dá para testar uma ideia de agente sem construir infraestrutura própria. E o fato de ser gerenciado significa que você não opera servidores para isso.

## Como começar

Acesse o anúncio oficial e crie uma conta na plataforma da OpenAI. O beta é público, então o caminho é solicitar acesso e ler a documentação da API. Depois, monte um agente mínimo com o harness do Codex e valide a lógica específica do seu caso — o resto fica com a OpenAI.
