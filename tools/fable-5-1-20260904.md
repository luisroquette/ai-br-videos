# Fable 5.1

O arquivo contém o que parece ser o prompt de sistema completo do Fable 5.1, um modelo da família Claude. São mais de 270 mil caracteres de instruções. O documento revela 16 novas ferramentas, um redesenho da memória, guardrails de segurança expandidos e instruções de busca reorganizadas. Foi publicado no GitHub e circulou com o comentário de que "não deveria ser gratuito".

## Por que importa

Prompt de sistema real com esse nível de detalhe é raro. Dá para ver como os guardrails são estruturados, como o modelo decide entre as ferramentas e como a memória de longo prazo foi redesenhada. Nada de especulação — o documento está lá, completo, para quem quiser estudar.

## Como começar

Abra o arquivo no GitHub. Leia primeiro as seções de ferramentas e segurança — são as que mostram mudanças concretas. Depois compare com a documentação pública da Anthropic para mapear o que é novo. As seções de memória e busca são as mais densas; vale ler com calma.
