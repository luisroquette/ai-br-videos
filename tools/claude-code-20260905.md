# Claude Code

Andrej Karpathy, cofundador da OpenAI, publicou um fluxo simples para transformar o Obsidian em um segundo cérebro com IA. A ideia: em vez de usar IA para gerar código, use para organizar e conectar tudo o que você lê. O processo envolve apontar o Claude Code para um vault doimportante do Obsidian e deixar que ele crie uma estrutura de pastas que separa fontes brut
brutas, anotações processadas e instruções de uso. Depois, basta jogar artigos, PDFs ou transcrições na pasta certa e fazer perguntas — o Claude responde com base no material que já foi ingerido.

## Por que importa

A maioria das pessoas usa IA para produzir conteúdo, não para absorvê-lo. Esse método inverte a lógica: a IA vira uma camada de conhecimento acumulado, que cresce conforme você alimenta. O resultado é uma base de dados pessoal consultável, sem depender de ferramentas caras ou configurações complexas. É uma forma prática de transformar leitura dispersa em conhecimento estruturado.

## Como começar

1. Instale o Obsidian e crie um vault vazio.
2. Abra o terminal na pasta do vault e execute o Claude Code.
3. Cole a ideia do Karpathy (ou peça para ele replicar o conceito) e instrua o Claude a criar a estrutura: pastas `raw`, `wiki` e um arquivo `CLAUDE.md`.
4. Coloque qualquer fonte (artigo, PDF, transcrição) na pasta `raw`.
5. Faça perguntas ao Claude sobre o conteúdo — ele vai consultar o que já foi processado.

O ciclo é simples: alimente, pergunte, refine. O conhecimento acumula com o tempo, e a IA fica mais útil a cada adição.
