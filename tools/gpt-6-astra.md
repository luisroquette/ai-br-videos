# GPT 6 Astra

O GPT 6 Astra é uma ferramenta que gera vídeos completos a partir de um único prompt, com base no Remotion. O exemplo que circulou mostra um comercial para a BridgeMind produzido sem edição manual: o Astra escreveu o código, renderizou as cenas e ainda compôs a trilha sonora — não via serviço externo como Eleven Labs, mas gerando áudio por conta própria, com Python.

## Por que importa

O diferencial não é "fazer um vídeo". É o fluxo: uma única chamada resolve roteiro, motion design e música em código, sem abrir editor. Para quem já trabalha com automação, isso significa menos dependência de ferramentas pagas e mais controle sobre cada frame. O áudio gerado via Python demonstra que o modelo não só escreve código, mas coordena bibliotecas e dependências para fechar o entregável.

## Como começar

O repositório `3641397194-wq/gpt6-Astra` tem o código e as instruções de execução. O caminho direto: clone o projeto, instale as dependências do Remotion e rode o script de exemplo com sua chave de API. Depois, adapte o prompt para seu próprio roteiro. Se quiser testar a geração de música, um bom primeiro passo é replicar o vídeo de exemplo antes de mudar qualquer coisa.
